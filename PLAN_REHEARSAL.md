# Репетиция с Питом: мини-игра из вкладки «Память» (план, 2026-10-28)

Переосмысление вертикальной игры «Повтори за диктором» (`src/features/player/modules/rotate-phone/`) как тренировки:
вспомнить слова игрой, потренировать дикцию и порядок слов. Запускается из вкладки «Память» на данных человека,
а не из ноды урока (нода `rotate_phone` остаётся как «репетиция, заданная автором», на том же движке).
Опора на исследования — сводка в PROJECT.md → «Репетиция с Питом» (после реализации) и в чате 2026-10-28:
эффект проговаривания, припоминание сильнее повтора, shadowing для ритма, обратное наращивание (backchaining),
просодия обучаема, чёткая артикуляция понятнее, конкретная мгновенная обратная связь (ELSA), «зеркало» своего голоса.

## Принятые решения (владелец, 2026-10-28)
| № | Решение |
|---|---|
| 1 | Голос диктора для фраз — **ElevenLabs** с таймингами слов (кнопка «Озвучить фразу» в админке «Модули», конвейер как у сцен), поле `curricula.phrase_audio`; запасной путь — голос из видео, затем системный синтез. |
| 2 | **XP за репетицию настоящий**, с дневным потолком, как в «Скажи вслух» (`say_aloud_result`). Промах слова → повтор завтра, шаг не меняется. |
| 3 | Раунд **«Различи» остаётся в основе, но переосмыслен**: запутыватели — из памяти самого человека (слова, которые он путает: `lapses`, промахи «Скажи вслух»); пара «слышу → говорю» (тап по дорожке, затем сказать слово — Vosk с закрытым словарём из той же тройки); только если у фразы дня есть известный «двойник», не дольше 15 с, иначе акт пропускается. |
| 4 | **«Зеркало»**: дубль всей фразы пишется MediaRecorder из того же потока микрофона, никуда не сохраняется; «Сравнить» играет диктора, затем человека, пилюли подсвечиваются по словам на двух полосах; Пит даёт ОДНУ заметку только из измеримого (пропуск слова, порядок, темп относительно диктора, паузы, громкость). Качество звуков не оцениваем — Vosk этого не умеет. |
| 5 | Перед сценарием — **разбор и починка индикации** текущей игры (см. ниже), иначе новый сценарий ляжет на кривую обратную связь. |

## Что репетировать сегодня (правило выбора)
- Слова с `word_memory.due_on ≤ сегодня`, по давности; группировка по модулю-фразе через урок-слово (`wordLessonsOf`).
- Фраза дня — где больше всего слов «к повтору» и есть озвучка; разминка — 2–3 слова из других фраз.
- Нет слов к повтору — фраза из `phrase_memory` с самой старой `consolidated_at`; пусто — кнопки нет (как «Скажи вслух» при < 3 слов).
- Одна фраза не чаще раза в 3 дня. Гость — локальная память, без XP.

## Сессия, ~90 с, пять актов
1. **Разминка** (15 с): Пит показывает перевод, человек говорит слово (готовый `sayAloudFlow`).
2. **Ритм** (10 с): диктор один раз, ударные слова подсвечены, человек тапает в такт (ударные — разметка в редакторе, словарь позже).
3. **Сборка с конца** (25 с): ступени [2], [1,2], [0,1,2]; диктор 1 раз, человек 1 раз; на последней — «теперь чётко, как для сцены», затем «а теперь обычно».
4. **Без подсказки** (15 с): текст убран; застрял — Пит подсказывает первое слово. (Сюда же «Различи», если есть двойник.)
5. **Дубль и зеркало** (25 с): запись, сравнение, одна заметка Пита.
Итог: фраза, темп, заметка, XP; слова в память; «Ещё минутку?» → вторая фраза (этап D).

## Индикация — жалобы владельца (разобрать до реализации)
1. При двух и больше словах первая пилюля мигает «неверно», вторая «верно», повтор засчитывается верным (partial Vosk → промах через 550 мс → final переписывает).
2. Микрофон-логотип слабо и с задержкой реагирует на голос.
3. Заливка пилюль наклонными полосками читается как ошибка.
4. При трёх словах сцена подлагивает — оптимизация сцены целиком.
5. Кот в этой сцене — обновить до «живого Пита v2» (рот по буквам и громкости, зрачки, усы).

## Этапы
0. Индикация и производительность (по разбору), кот v2 в игре.
1. Выбор «что репетировать» + кнопка «Репетиция» во вкладке «Память», пустые состояния, вход из «Ещё минутку?».
2. Сценарий пяти актов поверх движка; «Различи» по-новому; зеркало; заметки Пита; экран итога.
3. Озвучка фраз в админке (ElevenLabs, `phrase_audio`, миграция), строка в «Запуске».
4. RPC результата (по образцу `say_aloud_result`), журнал репетиций (фраза, дата, темп, заметка), события.
5. Тексты Пита-коуча на утверждение. 6. E2E, видео, `CHECK_NEW_USER.md`, проверка Vosk на телефоне.
