# Стенд пилюль (отладка)

Зачем: владелец подозревает, что Vosk «додумывает» сказанное, а пилюля реагирует нечестно (ложные срабатывания, медленно, не синхронно с голосом). Стенд — место, где есть
ТОЛЬКО настоящая пилюля игры и Vosk: без Пита, реплик, конвейера, узора ленты, нот и наград. Всё, что произошло, пишется в трассу; можно записать «видео» и листать его по кадрам.

## Вход
- Плашка «Голосом / Пальцами» «Встряхни память» при включённой отладке (тумблер админки «Отладочный интерфейс» `player_debug_ui` или `localStorage pithy_wl_debug_v1 = 1`) —
  под «Начать с: …» кнопка **«🧪 Стенд пилюль»** (`pitrace/RaceAskPlate.jsx`). Обычным пользователям не рендерится. Стенд — отдельный кусок сборки (lazy).
- Полноэкранный портал, «✕ выход» сверху (safe-area). Микрофон — по кнопке «Старт» (тап, iOS), тот же поток, что у игры (`openGameMic`); на выходе дорожка выключается (`closeGameMic`).
- Модель: английская держится, пока открыт стенд (`useVoskReady`; нет в кэше — уведомление «Нужно скачать»). «RU» — то же переключение слуха, что в игре (`raceSwitch.js`):
  английская выгружается, русская грузится; «EN» и выход — обратно.

## Режимы (панель сверху)
| Режим | Что за пилюля | Код игры |
|---|---|---|
| Слово (вертикальная) | пилюля «Пинг-понга»: EN — говорят английское слово, на пилюле перевод (проход A); RU — говорят перевод, на пилюле английское (проход B) | `createStudentGame` / `stepStudent`, ворота голоса, `createFillView`, `snapPill` / `missPill`, слушатель слов `createWordListener` (EN / RU) — `standWordRun.js` |
| По словам (проход 1) | широкая пилюля «Скажи»: маска-кирпичики, подсказка, слова по порядку и откат, рывок на неверное слово | `runPhraseScene` + слушатель фраз `createPhraseListener` (`wordByWord`) — `standPhraseRun.js` |
| Быстро (проход 2) | та же фраза открытым текстом, заливка glide | то же, `pass 2` |

- Пилюля **не летит**: пул игры «на месте» (`standPool.js`: без полёта, сразу на высоте 34 % / 33 %, без взлёта). «Не успел» на стенде не бывает — цель ждёт, пока её скажут или нажмут «Следующая».
- Зачёт — вспышка и заливка 100 % (как в игре), под пилюлей «зачёт ✓ ratio, чисто / нечисто, N мс от конца голоса» (или «за N мс до конца» — зачёт пришёл посреди речи);
  «авто» — новая цель через 0,6 / 1,2 / 2 с (можно выключить).
- Цели — `pillStandData.js` (слова и фразы с переводом + дежурные слова и фикстура фраз игры), длина «короткие» (слово ≤ 6 букв, фраза ≤ 3 слов) / «длинные» / «любые»,
  выбор — по сиду (`rngFor`, сид виден и правится в панели): та же сессия повторяется. Подряд одна и та же цель не выпадает.
- Русские фразы слушает русская модель; слова фраз сравниваются в латинице (`racePhraseLatin.js` в `racePhraseForms.normForms`), английское сравнение не меняется.

## Что слышит Vosk (под пилюлей)
Уровень микрофона (полоска, отметка — порог голоса стенда 0,015 = 2,5 × затвор тишины), затвор тишины, текущий черновик и история черновиков (+мс от появления цели), итоги с «кто закрыл»
(движок сам / кнопка «Стоп» / авто-стоп) и conf слов (`setWords`), совпадение (лучший кандидат и ratio / статус слушателя), засчитанные слова по порядку (ч — черновиком), откаты, неверные слова,
задержки: голос → первый черновик, конец голоса → зачёт, слово → заливка дошла.

**Цвета слов Vosk** (`pillStandColor.js`, `PillStandVoskWords.jsx`, переменные `--vw-*` в `pill-stand-colors.css`): под целью крупно (19 px) строка «Vosk черновик: …» / «Vosk итог: …» — текущий черновик или
последний итог пословно в цвете, ниже легенда мелкой строкой; той же раскраской — черновик, итоги и история в панели. Засчитанное слово цели — зелёный (пока только в черновике — светлее, курсивом), слово
цели, ещё не засчитанное, — голубой (итог) / серо-голубой курсивом (черновик), слова нет в цели — оранжевый с волнистым подчёркиванием, засчитанное и откаченное — зачёркнуто. «Засчитано / откат» — по событиям
трассы текущей цели (последнее событие слова решает). В плеере — та же строка для кадра (черновик / итог кадра, засчитанное к его моменту).

**Прошлые цели** (`pillStandHistory.js`, `PillStandHistory.jsx`, v3.3.180): под крупной строкой «Vosk: …» — последние 5 прошлых целей одной строкой «#4 wonderful → Vosk: «wonderful» ✓ 320 мс»
(последний итог, иначе черновик, в цвете; исход ✓ / ✗ / —; задержка «конец голоса → зачёт»), новая сверху. Строка закрывается тем, что панель знала ДО появления следующей цели — при «авто» ничего не
теряется; стирает только «очистить».

**Честный зачёт слова** (`player/modules/rotate-phone/wordEarRule.js`, общий для стенда и «Пинг-понга», `createWordListener({ earRule: true })`): Vosk с грамматикой «цель + [unk]» выдаёт цель в черновике уже
по началу звука (замер: черновик «wonderful» через ≈ 270 мс голоса и при 40 % слова). Поэтому: в грамматике — «ловушки»-начала слова («won», «wonder», «inter», «beauty»; которых нет в словаре модели,
Vosk выбрасывает), ловушка — ни зачёт, ни промах; черновик слова в 1 слог — сразу, в 2 — когда голос ≥ 240 мс, от 3 слогов — только итогом: голос кончился (тишина 150 мс) — итог захода просим сразу
(`stop('ear')`: без ожидания куска, хвост тишины 150 мс), засчитывается слово с conf ≥ 0,7 и голосом ≥ слоги × 120 мс. Журнал `[word-ear] черновик «wonderful» на 270 мс голоса (3 слога, ожидаю ≥ 360) — жду итог`,
`… итог «wonderful»: wonderful conf 1, по Vosk 780 мс, голос 690 мс (ожидаю ≥ 360) — зачёт`; в стенде — события `wl` `{ kind: 'ear' }`. Замер — `_stand/word_ear/index.html`.

**Здоровье микрофона** (`standMicHealth.js`, `useStandMicHealth.js`, v3.3.180): слушатель отдал `dead`, уровень ровно 0 дольше 2 с, дорожка `ended` / `mute` → `mic-dead { why, readyState, muted, attempts }`.
Тишина — переоткрытие тем же путём, что игра (`shared/lib/gameMicRenew.js`: `dropGameMic` + `openGameMic`), слушатель и пилюля той же цели — заново (`mic-revive { how: 'авто' }`); снова оглох за 8 с,
дорожка оборвана или заглушённая не ожила за 1,5 с — крупная красная плашка «Микрофон отключился — нажми, чтобы включить» (getUserMedia в тапе, `mic-revive { how: 'тап' }`).

## Режимы на лету
Язык EN / RU, режим «Слово / По словам / Быстро», длина и «авто» меняются в любой момент, не выходя из стенда и без повторного «Старт»: новая цель → пилюля и слушатель пересоздаются (эффект запуска
пилюли), микрофон (`openGameMic` — один раз) и контекст захвата Vosk остаются; смена языка — переключение слуха (пока оно идёт, пилюля стоит, «EN / RU» неактивны). Идущая запись **продолжается**
через смену (кадры и звук не рвутся), в трассе — события `prefs` / `lang` / `model` и новая `target`; отчёты «📤 Отправить» показывают `prefs` в хронике любой темы. Из плеера — «К стенду», затем смена.

## Трасса (тотальное логирование)
`pillStandTrace.js`: каждое событие — `{ t, k, … }`, t — мс от старта сессии (`performance.now`, 0,1 мс). Копия в журнал игры строкой `[stand] …` («Скачать журнал»); частые (уровень — не чаще 100 мс,
кадры заливки, повторные черновики) — только в трассу. Строки модулей игры (`[phrase-ear]`, `[gate]`, `[fill]`, `[phrases]`) — и в журнал, и в трассу (`log`).
| k | Что |
|---|---|
| `session`, `prefs`, `lang`, `model`, `mic` | открытие / сброс / выход, настройки, язык и этапы модели, микрофон |
| `target`, `run`, `target-run`, `run-stop` | новая цель (сид, режим, язык, текст), запуск пилюли и слушателя |
| `vosk-start` | словарь (grammar), отданный модели |
| `level` | rms каждого куска звука |
| `gate` | затвор тишины открыт / закрыт (rms) |
| `vosk-partial` / `same` | сырой черновик `{ partial }` / тот же текст повторно |
| `vosk-final` | сырой итог `{ text, result: [{ word, conf, start, end }] }`, stopBy, тайминги захода |
| `wl`, `listen` | разбор слушателя слов игры (seq, misses, статус), состояние слушателя |
| `word`, `phrase`, `ear` | onWord (index, draft, gone — откат), onPhrase (ratio), onEar слушателя фраз |
| `pill` | события движка пилюли: spawn / claim / snap / win / miss / fail |
| `fill` | цель и экран заливки (каждое изменение кадра) |
| `reach` | слово → заливка на экране дошла до новой цели, мс |
| `result` | зачёт: ok, ratio, clean, мс от конца голоса |
| `rec-start`, `rec-stop`, `view`, `export` | запись, просмотр, выгрузка |

## Запись и просмотр
- «● Запись» — снимок кадра каждый rAF (≤ 60/с, ≤ 3 минуты, за 30 с до конца кнопка краснеет): атрибуты пилюли, заливка на экране и цель, кромка, вычисленные scale / transform /
  outline (хлопок и дрожь — WAAPI), вспышки щелчка, маска слов (скрыто / подсказка / белое), панель Vosk (черновик, итог, затвор, rms). DOM не клонируется — лёгкий объект.
- Звук — MediaRecorder на том же потоке микрофона: iPhone (Safari 14.3+) — `audio/mp4`, Chromium — `audio/webm;codecs=opus`; нет — запись без звука с пометкой.
  Видеозаписи экрана на iOS нет (getDisplayMedia), поэтому «видео» — точное воспроизведение кадров той же пилюлей из снимков (CSS-анимации в плеере выключены) + звук.
- «▶ Просмотр»: таймлайн, ▶ / ⏸, луп (по умолчанию вся запись; A / B — границы, «весь»), скорость 1× / 0,5× / 0,25×, покадрово ◀ ▶ (кнопки; на компьютере — стрелки, пробел — пауза).
  Под кадром: время, номер, заливка (цель / экран), Vosk кадра, события этого кадра (подсвечены) и ±200 мс. Пока идёт просмотр, пилюля и слушатель стенда стоят.

## Честность (сводка и панель)
`pillStandHonesty.js` по отрезкам целей: ложные срабатывания — слово / счёт / заливка без голоса (куска звука громче 0,015 не было 1,5 с и затвор закрыт), черновик без голоса, засчитанное слово,
которого нет в итогах Vosk после него («без итога» — зачёт по черновику, заход закрыт — отдельно, не ложное); «додумывание» — слова черновиков и итогов, которых нет в цели, и перестройки
черновика (новый текст — не продолжение прошлого); задержки (медианы) — голос → первый черновик, слово → заливка дошла, конец голоса → зачёт.

## Выгрузка
- «Сводка» — текст в буфер: шапка (версия, устройство, сид, режим, язык), итоги честности, по каждой цели — голос, черновики и итоги с мс, засчитано, откаты, неверные, додумано, ложные, зачёт, задержки.
- «⬇ Трасса» — JSON `pithy-pillstand-…json` (meta, targets, events, frames, audio — формат и смещение) и звук отдельным файлом (`.m4a` / `.webm`) через `saveDebugFile`
  (iPhone — лист «Поделиться» или новая вкладка). В плеере — то же для записи.

## Отправка по теме («📤 Отправить»)
Кнопка «📤 Отправить» — в шапке панели «что слышит Vosk» и в плеере. Окно — лист снизу (`PillStandSend.jsx`, состояние — `useStandSend.js`; форма держится между открытиями):
- **О чём замечание** — галочками одна или несколько тем: «Анимация», «Распознавание (Vosk)», «Зачёт и логика», «Честность», «Всё» (поглощает остальные).
- **Отрезок** — вся сессия · цель (по умолчанию «авто»: текущая, а если в ней ещё ни голоса, ни исхода — вместе с прошлой, где они были; или явно одна из последних 5 — «#4 wonderful ✓»;
  всегда с 1 с до появления цели; плеер — цель кадра) · A–B из плеера (если отмечен; держится и после «К стенду», новая запись — без A–B) · последние 10 / 30 / 60 с
  (до «сейчас»: в плеере — до текущего кадра).
- **Комментарий** своими словами (после отправки файлом или текстом комментарий и метки сбрасываются; закрыли лист без отправки — черновик остаётся); «◆ Отметить кадр N» (в плеере — текущий кадр, на живом экране — миг и ближайший кадр записи) — метки идут в файл; метку снимает тап по ней.
- **Звук** — галочка (по умолчанию вкл. для «Распознавания» и «Всего», выкл. для остальных, пока не тронута): звук записи отдельным файлом с тем же именем (`.m4a` / `.webm`), в шапке — где отрезок
  в звуке (секунды). Звук — вся запись (не режется: перекодирование на iPhone ненадёжно).
- «Отправить файлом» → `saveDebugFile` (на iPhone — лист «Поделиться», запасной путь — новая вкладка; на компьютере — скачивание). Звук на компьютере уходит сразу вторым файлом, на iPhone — кнопкой
  «📎 Звук» (второй «Поделиться» без нового нажатия Safari не откроет). «Скопировать текстом» — тот же отчёт без JSON-блока (и без таблиц кадров, если длиннее 150 000 знаков).

Пакеты тем (`pillStandPacks.js`, каждый описан явно):
| Тема | Что в файле | Чего нет |
|---|---|---|
| Анимация | кадры (таблица: t, кадр, цель, экран, маска слов «сказано · черновик* · (подсказка 0,20) · ░», флаги — lock / nudge / live…, хлопок, дрожь, обводка, вспышка; прорежено, но ВСЕ кадры ±300 мс вокруг меток и каждая смена состояния с кадром до неё), цель заливки (смены) и экран (шаг ≥ 0,05), «[fill]», «заливка дошла», события пилюли, слова слушателя и откаты, зачёт; моменты слов Vosk словами («Vosk черновик: «…» (новые слова: …)»); метрики: слово → заливка, рывки экрана «на голос ли», первые кадры флагов | сырой JSON Vosk, rms, затвор (и в кадрах JSON — только тексты панели Vosk) |
| Распознавание | сырые черновики и итоги (conf, start / end слов, «кто закрыл заход», тайминги захода), словарь, готовность / ошибки, затвор, rms (все переходы порога + раз в 250 мс в голосе, раз в 1 с в тишине), слух фраз, служебное слушателя (словарь, конец захода, стоп), микрофон / модель / язык, «[phrase-ear]», «[gate]»; метрики: голос → черновик, повторы и перестройки (было → стало), итоги, кто закрывал, додуманное, словарь | кадры, заливка |
| Зачёт и логика | счёт и разбор слушателя слов (seq / misses), onWord и откаты, onPhrase с ratio, движок пилюли, зачёт / промах, «[phrase-ear]» с решениями (кандидаты, договорена, без последнего слова, итог запрошен, откат), «[phrases]» (ход, продление у края), неверные слова; тексты итогов Vosk для контекста | rms, сырой JSON, кадры, заливка |
| Честность | метрики `pillStandHonesty.js` и каждое ложное срабатывание с голосом рядом (макс. rms за 1,5 с до, затвор); события-доказательства ±300 мс вокруг ложных и первых появлений «додуманных» слов | всё вне окон, rms-события, кадры |
| Всё | хроника — объединение тем + прочие события; JSON — трасса отрезка, прореженная как в «Распознавании» (уровень — переходы порога + раз в 250 мс / 1 с, повторы черновика — счётом, заливка — смены; `thinned`), все кадры (с панелью Vosk), весь журнал игры за отрезок | — |

Файл — один `.txt` `pithy-stand-<темы>-<дата>.txt` (`pillStandReport.js`): шапка (темы, версия, устройство, дата с поясом, режим / язык / длина / сид / авто, отрезок, «цели в файле» с исходом ✓ / ✗ / —, «микрофон: …» (сбои и оживления), метки, звук, итог честности
отрезка, состав) → «== Комментарий ==» → по каждой цели: «-- зачёт: ✓ по итогу — правило слова: ждали итог (…) --» (`pillStandVerdict.js`), хроника «+мс от появления цели» (словарь Vosk — «грамматика #N (585 вариантов, та же)»: целиком один раз в JSON `grammars`, `pillStandCompact.js`), таблица кадров (Анимация / Всё), метрики выбранных тем → «== Журнал игры ==» (строки `gameJournal` за отрезок: метка
performance.now → мс сессии; «Всё» — строки модулей игры без `[stand] …` и без повторов трассы, `[perf]` — раз в 5 с; остальные темы — только строки модулей игры своей темы без повторов трассы) → `---JSON---` и одна строка JSON (`kind: pithy-stand-pack`: header,
comment, marks, targets, events, frames, metrics, honesty, journal). Больше 2 МБ — предупреждение под кнопкой (для «Всё» — больше 15 МБ), файл всё равно уходит.

## Как пользоваться на iPhone
1. Админка → включить «Отладочный интерфейс» (или в консоли `localStorage.pithy_wl_debug_v1 = '1'`). Открыть урок с «Встряхни память» → «Встряхни память».
2. На плашке «Голосом / Пальцами» нажать «🧪 Стенд пилюль» → «Старт» (разрешить микрофон). Нужно скачать модель — «Скачать».
3. Выбрать язык (EN / RU), режим, длину. Говорить слово / фразу с пилюли; ниже видно, что слышит Vosk.
4. Нашли странное — «● Запись», повторить, «■ Стоп» → «▶ Просмотр»: ◀ ▶ по кадрам, 0,25×, луп.
5. «Сводка» → вставить в чат; при необходимости «⬇ Трасса» → «Поделиться» → отправить файлы (json и звук).
