# План: новый пользователь и первая сессия (решения 2026-10-25)

Файл для исполнителя (Fable или другой агент). Решения приняты владельцем в обсуждении, ниже — что делаем, в каком порядке и как понять, что готово.
Схема-источник: `lesson-drafts/new-user-first-session.scheme.json` (формат `pithy-lesson`, импортируется в канвас; пересобирается генератором `lesson-drafts/gen/gen-new-user-scheme.mjs`: `node lesson-drafts/gen/gen-new-user-scheme.mjs <файл.json>`).
Подробности и история решений — `PROJECT.md`, раздел «Новый пользователь: первая сессия — план».

## 0. Правила работы (из CLAUDE.md, коротко)
- Отвечать владельцу по-русски, коротко. В конце ответа — список изменённых файлов и **итоговое** число строк в каждом (без `version.js`).
- Любое изменение кода — `APP_VERSION` +1 (`src/shared/lib/version.js`). Новый файл — строка в `STRUCTURE.md`.
- Файл ≤ 400 строк (ориентир 250), один файл — одна ответственность; CSS тоже. `npm run lint` после крупных изменений.
- Изменения БД — только новым файлом `supabase/migrations/<YYYYMMDDHHMMSS>_<имя>.sql`, идемпотентно; **каждую миграцию показать владельцу целиком в чате** (длинную — частями по ~90 строк).
- Разработка от тестовой ветки `claude/cool-euler-bb396v`, пуш в неё без отдельной просьбы; в `main` — только по явной просьбе.
- Урок/схему в JSON отдавать после `node scripts/lesson-gate.mjs файл.json --fix-seq`. Для схем (не уроков) часть правил чата неприменима (третье лицо «Пит», «задания подряд», «нет таблиц») — это известно и принято, сообщать об этом.

## 1. Цель и принципы
1. Новому пользователю с пустой памятью лента даёт не только видео, но и короткие игры; уровень понимается по поведению и ответам, а не анкетой.
2. Ничего не валим сразу: интерфейс раскрывается по одному шагу, по поведению (прогрессивное раскрытие, см. раздел 8).
3. Пит (кот-проводник, **не блогер**) говорит по-русски, заботливо, без давления. Не «я напомню», а «Пит напомнит, когда пора повторить забытое»; не «слова лучше закрепляются».
4. Любой вопрос Пита закрывается без последствий. Все такие вопросы подчиняются одному бюджету (этап A1).
5. Слово «память» человек сначала видит как подпись иконки; подробный рассказ — только по его нажатию.
6. Гость получает то же, что вошедший; его данные в `localStorage` переезжают при регистрации.

## 3. Принятые решения
| № | Решение |
|---|---|
| 1 | Уровень = две оси: **ухо** (понимание на слух) и **словарь** (слова). Хранить с неопределённостью. Показывать человеку не число и не A1–C1, а слова Пита. |
| 2 | Прямой вопрос «Что тебе знакомо?» — **не в первой сессии** и не до первой пользы; рекомендуется в начале второго визита, всегда с «Пропустить»; подстраховка — после двух ответов «слишком просто/быстро». Формулировки — по самооценочной сетке CEFR, раздел «Слушание» (сверить с первоисточником). |
| 3 | Пит спрашивает **по поведению**, не по расписанию: после трёх быстрых пролистываний — «Кажется, не зацепило. Подскажешь, что не так?» (3 ответа: слишком быстро, не успеваю / слишком просто, хочется сложнее / всё хорошо, просто смотрю). После ответа — одна строка Пита на 3 секунды, дальше лента подстраивается молча. |
| 4 | Шторка «Выбери слово» в ленте строится на `word_choice`; **источник заданий — карточки колод повторения** (в них задание уже упаковано с контекстом). Второй модуль — «Напечатай слово» уже есть (это «Ловля слов»). |
| 5 | Игры ленты: «Дополни реплику» (слово заменено «мяу», на выбор три слова) и «Слово голосом → картинка из трёх» (`photo_choice`, озвучка слова из `word_audio`). Неверные варианты похожи по смыслу/звуку (sheep/ship/chip), не больше трёх. Показать «tried / tries» — тоже только текстом. |
| 6 | Звук проверяется **в момент показа** задания и во время него. Нет звука — текстовая версия. Значок сложности (три полоски) скрыт, пока не было первого прослушивания со звуком, потом плавно проявляется. |
| 7 | «Семена памяти»: правильный ответ в игре → «Чтобы не забыть слово, сохрани его» → «Сохранить / Не сейчас». Слово без колоды повторения не предлагаем. Первый раз слов «память» и «вкладка» нет. |
| 8 | Вкладка «Память» **скрыта** у нового пользователя до первого слова (из урока или из ленты). У кого слова уже есть — видна. После сохранения слово улетает в панель, иконка с подписью «Память» вспыхивает, строка «Здесь твои слова не потеряются» (3 с). Иконка мерцает до первого нажатия. |
| 9 | Первое открытие вкладки: Пит рассказывает (голос при включённом звуке, **субтитры всегда**; звука нет — только субтитры), ~15–20 с, без вопроса «слушать или читать». Заменяет текстовое окно `MemoryIntro`. |
| 10 | Пути в «Память»: иконка после первого слова; конец урока (слово улетает в панель); тап по уведомлению; Профиль → «Мои слова»; на втором визите карточка «Слово ждёт» в ленте. Все ведут к одному рассказу Пита. |
| 11 | Вопрос «Когда удобно учиться?»: «Пит напомнит, когда пора повторить забытое». Варианты 9:00 / 14:00 / 20:00, **своё время** (любые часы и минуты), «Не нужно, загляну сам». Подтверждение с конкретикой: «Готово. Завтра в 20:00 придёт одно уведомление про слово». «Сколько минут в день» при этом **не спрашиваем**, по умолчанию 5; подстройка — по факту (≥3 визита **и** ≥3 дня). |
| 12 | Часовой пояс — **с устройства** (название, например `Europe/Moscow`), не по IP: VPN IP меняет, настройки телефона нет. Хранить местное время напоминания и пояс, обновлять пояс при каждом визите. Пояс неизвестен — спросить, не подставлять «Москву». |
| 13 | Уведомления: на iPhone работают только у приложения, добавленного на экран «Домой», разрешение просим по тапу; отдельная ветка с честным предложением «Добавить на экран Домой». Отказ — не уговариваем. |
| 14 | Гостевой лайк/закладка работают сразу (`localStorage`), без формы входа; через слайд-два мягкое сообщение Пита «Сохраню лайки и закладки, если создашь аккаунт — это полминуты». Переносятся при регистрации. |
| 15 | «Ещё» после занятия ведёт в **игры ленты**, а не в дополнительное повторение (оно остаётся за подпиской Pro). |
| 16 | Первый слайд: обычное видео-ситуация (английский на слух) средней сложности, как зонд «проще или сложнее». Особое видео **не делаем сейчас** (решено 2026-10-25): измеряем досмотр первого слайда и возврат на 2-й день; особая сцена с котами — только если цифры слабые. |
| 17 | Мини-игра «Скажи вслух» (экран «Переверни телефон», Vosk) — в плане, **распознавание исключительно через Vosk** (системное не используем). См. этап E. |
| 18 | Сериал про Пита, «Слова дня», цель дня, лесенка из 5 слайдов — **позже**, отдельными инструментами; в первую сессию не входят. Серия одна для всех (без подстановки слов пользователя). |
| 19 | **Второй канал напоминаний (почта) не делаем.** Напоминания только уведомлениями; кто их не получает — видит пометку в приложении при следующем входе. |
| 20 | **Модель Vosk качается тихо, как сейчас.** Если человек зашёл туда, где Vosk нужен («Скажи вслух», «Сказать фразу»), а модель ещё не докачалась, — показываем уведомление «нужно скачать» (с кнопкой и прогрессом). Системное распознавание не подставляем, молча не ждём. |
| 21 | **Текст рассказа Пита о «Памяти» подготовит владелец позже.** Пока заглушка; озвучку (ElevenLabs) не записывать до утверждения текста; субтитры берутся из того же текста. |
| 23 | **Контрольная группа без «умных» вопросов Пита — постоянные 10% новых пользователей** (решено 2026-10-25). Пока трафик мал, она только копит данные: выводов не делать, пока в каждой группе нет порядка 1250 человек (оценка для разницы возврата в 5 п.п.). Механика ставится сразу, чтобы данные копились с первого дня. |
| 22 | В разборе «Изменения» **новая нода и изменённая подсвечиваются разными цветами** (новая — розовый, как сейчас; изменённая — второй цвет — **янтарный, подтверждён**). Нода с комментарием в прошлой версии **остаётся «изменённой»** (как сейчас), отдельного флажка нет. См. этап G. |

## 4. Этапы

### Этап A — фундамент (без видимого интерфейса)
**A1. Единый бюджет вопросов Пита** — `src/shared/lib/prompts/` (`promptBudget.js` правила и очередь, `promptRules.js` числа, `usePromptSlot.js` хук).
- Единый вид: шторка снизу, кружок Пита, ≤2 строк, ≤3 ответов, крестик всегда. Виды: вопрос, подсказка, предложение, напоминание.
- Бюджет: не чаще 1 на 5 слайдов и 1 вопроса «про человека» за сессию; первые 3 сессии ≤2 за сессию, дальше ≤3; не раньше 20 с после входа; не во время звука, ввода, сразу после ошибки или «не знаю»; пока показан один — второй ждёт.
- Приоритет: 1) объяснить только что сделанное (первое слово → «Память»); 2) то, о чём попросил сам; 3) вопрос по поведению; 4) подсказка интерфейса; 5) предложение игры; 6) просьба про уведомления.
- Защита: закрыл/смахнул дважды — вид на паузе 7 дней, трижды — 30; подсказки после 3 игнорирований снимаются навсегда; «Спроси позже» — пауза 3 ч, три подряд — 7 суток; вид с высокой долей закрытий выключается сам.
- Свести под бюджет существующие лимиты: «Ловля слов» (`features/feed/catch/catchLater.js`, `feedCatch.js`: раз в 5 видео, 3 в день), «О чём диалог» (`features/feed/scene/sceneTaskLimits.js`: 5 в день, пауза 3 ч), подсказки ленты (`features/feed/useFeedHint.js`, `slowmoHintPlan.js`). Старые лимиты остаются внутри.
- События: `prompt_shown`, `prompt_answer`, `prompt_dismiss` (props плоские: вид, id, ответ, мс) — в `src/shared/lib/analytics/eventNames.js` и **миграцией** `insert into public.app_event_names` (таблица белого списка).
- Контрольная группа без вопросов Пита — **постоянные 10%** (решение 23; описание механики — в разделе 7). Админ-выключатель обязателен: доля 0–50% настраивается, 0 = группы нет.
- В админке «Аналитика» рядом с разрезом по группе показывать **число людей в каждой группе** и пометку «мало данных — выводов нет», пока в группе меньше ~1250 человек. Без этой пометки легко принять случайность за результат.
- Готово, когда: юнит-тесты правил (все пункты бюджета, приоритет, паузы), старые лимиты не нарушены, события пишутся.

**A2. Оценка уровня** — `src/shared/lib/level/` (чистые функции, тесты).
- Входы: быстрый пролист, досмотр, `feed_slow`, `feed_reveal`, `feed_phrase_open`, голос сложности, `scene_task_answer`, `lesson_answer`, ответы «Ловли», итоги Старта (в общий профиль, не только в полоски слов), ответы Пита из B3.
- Выход: `ear` и `vocab` с неопределённостью; цель — 80–85% верных в заданиях (правило 85%, настраивается). «Пролистал слишком лёгкое» ≠ «пролистал слишком сложное»: сейчас `quick_skip_penalty` их не различает.
- Хранение: `user_profiles.ear_level real`, `ear_sigma real`, `vocab_level real` (миграция); гостю — зеркало в `localStorage` (как `guestMemory`).
- Сигнал `level_fit` в `src/shared/lib/ranking/signalRegistry.js` (сначала `collecting`, потом `live`), вес в админке; раз в 4–5 слайдов «рывок» на ступень выше.
- Готово, когда: тесты на последовательности событий (лёгкое → уровень вверх, сложное → вниз, шум не двигает), сигнал виден в админке.

**A3. Напоминания по своему времени** — миграция + `supabase/functions/push-trigger/`.
- `user_profiles.remind_at time`, `remind_enabled boolean`, `next_remind_at timestamptz`; пояс — существующий `user_profiles.tz` (приходит из `touch_daily_login`).
- Убрать запасной `coalesce(p.tz, 'Europe/Moscow')` в SQL пуша повторения (`20260925180000_push_review_due.sql`); пояс неизвестен — не слать и спросить. Такой же запасной пояс есть в серии (`20260831120000_streak_by_lesson.sql`) — там менять осторожно, это граница суток серии: отдельно согласовать с владельцем.
- Прогон чаще часа (5–15 мин) по `next_remind_at`; после отправки пересчитывать с учётом перехода на летнее/зимнее время.
- Деплой функции вручную: `supabase functions deploy push-trigger --no-verify-jwt`.
- Готово, когда: тесты на SQL (разные пояса, смена пояса, лето/зима, время вроде 7:40), показан результат владельцу.

### Этап B — лента для нового пользователя
**B1. Состояние «новый» и скрытая «Память»** — `src/app/ShellNav.jsx`, `features/learn/memoryFresh.js`.
- «Новый» = нет слов в памяти (гость тоже). Вкладка скрыта; при первом слове появляется (полёт слова в значок уже есть). Иконка мерцает до первого нажатия, затем навсегда обычная.
- Есть режим проверки «Я новенький» (`shared/lib/newbieSim.js`): им тестировать.

**B2. Подсказки по поведению** — `useFeedHint.js`, `DifficultyBadge.jsx`, чип звука.
- Звук: через ~8 с без включения один раз чип «Послушаем?» + строка «Если сейчас неудобно — можно и без звука, текст под видео».
- Замедление: дважды пауза на фразе или переслушал; перевод фразы («потри»): открыл фразу, перевод не трогает; перевод слова: тап по слову. Не больше одной подсказки за сессию.
- Значок сложности скрыт без первого прослушивания и плавно проявляется после (чужая оценка не должна задавать ожидание заранее).

**B3. Пит-вопрос по поведению** — шторка бюджета A1 с тремя ответами (формат «выбери слово»), реакция Пита на 3 секунды, сдвиг уровня (A2).

**B4. Шторка «Выбери слово» в ленте** — новый компонент по образцу `features/feed/scene/SceneTaskSheet.jsx` и `features/feed/catch/CatchCover.jsx`; задания из карточек колод (`features/review/reviewDecks.js`, `reviewCards` в JSON урока). Контекст карточки (1–3 ноды) + `word_choice`.

**B5. Игры** — «Дополни реплику»: озвученная реплика сцены/видео, на месте слова «мяу» по `wordTimings` (играть до начала слова, мяу, дальше), три слова; «Слово голосом → картинка»: `photo_choice` (картинки с `imagePrompt`, генерация Gemini уже есть) + `word_audio`. Звук проверять в момент показа; нет звука — текстовая версия. Карточки с `photo_choice` в колодах сейчас почти нет — нужна авторская работа.

**B6. Семена памяти** — кнопка «Сохранить слово» после верного ответа; слово без колоды не предлагать; серверная запись нового слова (новый RPC `memory_seed_word` или расширение существующих `memory_catch_*`, миграция); гостю — `guestMemory`.

**B7. Гостевой лайк** — `localStorage`, перенос при регистрации, мягкое сообщение Пита (сейчас гостевой лайк открывает форму входа).

### Этап C — «Память» и напоминания
**C1. Первое открытие вкладки** — рассказ Пита (озвучка ElevenLabs ~15–20 с + субтитры), заменяет `MemoryIntro.jsx`.
- **Текст — заглушка** (решение 21): вынести в один файл `src/features/learn/memoryStoryText.js` (текст, адрес озвучки, подпись кнопки), чтобы владелец мог подставить свой текст и позже добавить озвучку **без правок логики**. Нет файла озвучки — только субтитры. Заглушка нейтральная и короткая; не выдавать за финальную.
- Критерии для будущего текста (отдать владельцу): ~40–50 слов (15–20 с речи), по-русски, без лекции и без давления, в конце подвод к вопросу «Когда тебе удобно учиться?». Черновик, который обсуждался: «Это твоя Память. Сюда попадают слова, которые ты сохранил. Забывать слова — нормально. Поэтому они растут: сначала новые, потом знакомые, потом усвоенные. Я подскажу, когда пора вернуться к слову, чтобы оно осталось с тобой. А теперь скажи, когда тебе удобно учиться?» (решения по нему — за владельцем).
**C2. «Когда удобно учиться?»** — шторка в конце рассказа: пресеты, колесо «своё время» со строкой «по твоим часам сейчас …», подтверждение, ветка уведомлений (разрешено / iPhone без «Домой» / отказ). `MinutesAsk` убрать из онбординга (минуты — по умолчанию 5, подстройка по факту).

### Этап D — возврат (сначала отдельная схема)
Схема возврата: день 2 и дни 3–5, по числу визитов и дней вместе; карточка «Слово ждёт»; подстройка минут («заметило и подстроилось»); «ещё» → игры ленты. Делается **следующей схемой в канвасе**, затем реализация.

### Этап E — мини-игра «Скажи вслух» (Vosk, только он)
- Идея: Пит показывает перевод, человек называет английское слово вслух; 60–90 с, 5–8 слов «к повтору»; на основе визуала «Переверни телефон» (дорожки, круг, реагирующий на голос).

### Контрольная группа: как это работает (решение 23: 10%)
- **Зачем.** Если мы просто включим вопросы Пита и возврат на 2-й день вырастет или упадёт, непонятно, из-за вопросов или из-за всего остального (другой релиз, сезон, источник трафика). Единственный честный способ — сравнить тех, кто видит вопросы, с теми, кто нет, в одно и то же время.
- **Как делим.** Стабильно по `anon_id`/`user_id`: `hash(id) % 100 < доля`. Группа запоминается в `localStorage` и в профиле, при регистрации гостя переезжает с ним (иначе он «перескочит» из группы в группу). Событие `app_open` и все `prompt_*` несут признак группы.
- **Что скрываем у контрольной группы:** вопросы по поведению (B3), предложения игр, подсказки интерфейса, предложение «Скажи вслух». **Что показываем всем:** объяснение «Памяти» после первого слова, «Когда удобно учиться?», просьба про уведомления, ответ на кнопку «?» — это функциональные шаги, а не «умные вопросы».
- **Что сравниваем:** главное — возврат на 2-й и 7-й день; дополнительно — доля сохранённых слов, длина первой сессии, доля закрытых вопросов, жалобы. Пороги фиксируем до запуска.
- **Размер выборки.** Чтобы увидеть разницу в возврате на 2-й день, например 25% против 30% (5 процентных пунктов), при обычных допущениях (80% мощность, уровень значимости 5%) нужно примерно **1250 человек в каждой группе**. Если в группу идёт 10% новых, то для набора нужно около 12 500 новых пользователей за время теста; при 100 новых в день это 4 месяца. Поэтому при малом трафике постоянные 10% почти ничего не покажут, а временный тест 50/50 даст ответ за 2–3 недели. Чем меньше эффект, который надо различить, тем больше людей нужно (для 3 п.п. — примерно втрое).
- **Цена для людей.** Контрольная группа получает то же приложение без «умных» подсказок — это не ухудшение, а прежнее поведение. Если вопросы помогают, эта группа теряет; если мешают — выигрывает. Данных о людях сверх уже собираемых (`anon_id` в `app_events`) не нужно.
- **Страховка.** Если через неделю у группы с вопросами возврат заметно хуже (заранее заданный порог), вопросы выключаются админ-выключателем.
- **Где смотреть.** Вкладка «Аналитика» в админке уже есть (`AdminAnalyticsTab.jsx`); нужно добавить разрез по группе.

## 8. Опора на исследования и честные оговорки
- Покрытие слов 95–98% для понимания на слух (van Zeeland & Schmitt; год в источниках 2012/2013) → цель «новых слов во фразе 2–5%».
- Правило 85% (Wilson 2019) доказано на простых задачах классификации; для языка — аналогия, число настраиваемое.
- Вспоминание лучше повторного чтения (Rowland 2014, по пересказам); выбор из вариантов может закрепить ошибку (Roediger & Marsh 2005) → ≤3 варианта, сразу верный ответ.
- Картинки помогают запоминать слова — данные расходятся, на это не опираемся.
- Планирование «если–то» повышает достижение целей (Gollwitzer & Sheeran 2006, d≈0,65, по пересказам); привычка формируется за недели (Lally 2010, медиана 66 дней, разброс 18–254).
- Эффект произнесения вслух (MacLeod 2010); перенос на слова второго языка — Icht & Mama 2019 (не проверен).
- Награды могут снижать внутренний интерес (Deci 1999, d −0,28…−0,40) → XP мал и не объявляется целью.
- Прогрессивное раскрытие (Nielsen), обратная связь после действия (NN/g). Подсказки «по месту» против вводного тура — только вендорские блоги, не доказательство. «Не задавать личные вопросы до первой пользы» — наш принцип, не доказан: проверять возвратом на 2-й день.
- Социальное влияние: положительные оценки других сдвигают мнение следующих (Muchnik, Aral, Taylor 2013) → значок сложности после первого прослушивания.
- Пуши на iPhone: только для приложений на экране «Домой», разрешение по тапу (документация OneSignal/Pushpad).
