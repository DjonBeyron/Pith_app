# Проверка руками: новый пользователь и первая сессия (v3.3.28, тестовая ветка)

Адрес тестовой ветки: https://pith-app-git-claude-cool-euler-bb396v-djonbeyrons-projects.vercel.app/
Наверху приложения мелко — номер версии: должно быть **3.3.28** или выше (иначе кэш, обновите страницу).

## 0. Перед началом (один раз)
1. **Миграции.** Применены 2026-10-27 (13 файлов `supabase/migrations/20261027*.sql`). Проверка, что всё на месте: Admin → Аналитика открывается без ошибки, а в SQL Editor `select name from app_event_names where name like 'prompt_%' or name in ('memory_seed','say_aloud_round')` даёт 5 строк.
2. **Пуши по своему времени.** Деплой функции — кнопкой: GitHub → Actions → «Deploy Supabase functions» → Run workflow → ветка `claude/cool-euler-bb396v`, функция `push-trigger` (один раз добавить секреты `SUPABASE_ACCESS_TOKEN` и `SUPABASE_PROJECT_REF` в Settings → Secrets → Actions). Затем cron раз в 10 минут в SQL Editor (команда в шапке `20261027120000_remind_time.sql`, подставить ref проекта и секрет из job «evening»).
3. **Доля контрольной группы.** Админ → **Аналитика** → «Контрольная группа без вопросов Пита» → поставить **0 %** и «Сохранить» на время проверки (иначе с вероятностью 10 % устройство попадёт в группу без вопросов Пита, и шагов 3–5 ниже не будет). После проверки вернуть 10 %.
4. **Включить «Я новенький».** Админ → блок **«Переключатели»** → «Я новенький (первый вход)». Страница перезагрузится: вы видите приложение как гость с пустыми данными, свои данные целы. Каждое включение начинает песочницу с нуля — так можно повторять сценарий сколько угодно.

Полезно держать открытой консоль браузера (F12 → Application → Local Storage): ключи песочницы начинаются с `nb:`.

## 1. Лента: вкладки и первый слайд (B1, B2)
- [ ] Внизу **три** вкладки: Уроки, Профиль, Рейтинг. **«Памяти» нет.**
- [ ] На первом слайде **нет значка сложности** (три полоски). Он появится только после первого прослушивания со звуком (3 с видео со звуком) и проявится плавно.
- [ ] Звук не включать ~8 секунд → снизу шторка с кружком Пита: «Эти фразы лучше слышать.» и кнопки **«Послушаем?» / «Без звука»**. «Послушаем?» включает звук; «Без звука» — реплика «Если сейчас неудобно — можно и без звука, текст под видео» на 3 с.
- [ ] Крестик на любой шторке Пита закрывает её; смахивание вниз — тоже.
- [ ] Шторки Пита приходят **не раньше 20 с после входа**, не чаще **1 на 5 слайдов**, в первые три сессии **не больше 2 за сессию**. Если «ничего не приходит» — это бюджет, а не поломка: выключите/включите «новенького» (новая сессия) или полистайте 5 слайдов.

## 2. Подсказки по поведению (B2)
Не больше одной подсказки за сессию (все вместе). Чтобы увидеть другую — новая сессия (переключить «новенького»).
- [ ] Две паузы на одной фразе (тап по видео) или свайп назад → подсказка «Не успеваешь? Зажми над сердечком — видео замедлится.»
- [ ] Открыть фразу из-под шариков и 7 с не трогать перевод → «Потри фразу пальцем — появится перевод.»
- [ ] Два слайда подряд открыть перевод фразы, не тапая по словам → «Тапни слово — увидишь его перевод.»

## 3. Вопрос Пита по поведению (B3)
- [ ] Пролистать **три слайда подряд быстрее 2 секунд** каждый (после 20 с с момента входа) → шторка «Кажется, не зацепило. Подскажешь, что не так?» с тремя ответами.
- [ ] Выбрать ответ → реплика Пита 3 с («Понял. Пит подберёт что-нибудь поспокойнее» и т. п.) → шторка уходит. Повторно за сессию вопрос не задаётся.

## 4. Игры ленты (B4, B5)
Предложение игры приходит через бюджет Пита: после 3-го слайда грузятся колоды, затем не чаще раза в 6 слайдов и не больше 4 в день. Игры чередуются: «Выбери слово» → «Дополни реплику» → «Картинка». У игры нет материала — она пропускается.
- [ ] Шторка «Пит нашёл игру на минутку — выберешь слово?» → **«Давай»** → шторка с карточкой колоды (контекст + «Выбери слово»). **«Не сейчас»** — ничего.
- [ ] Без звука карточка идёт текстом (ноды со звуком убраны, плеер без звука).
- [ ] Ответ → «Верно!» или «Не то — верно: …» → «Дальше».
- [ ] «Дополни реплику»: реплика с озвучкой из колоды (нода `audio` или сцена с таймингами слов): звук играет до слова, пауза 350 мс с надписью **«мяу»**, дальше; три слова на выбор. Если в колодах нет озвученных реплик с таймингами — игра не предлагается (это ожидаемо; звука «мяу» в проекте нет — пауза).
- [ ] «Картинка»: предлагается только при наличии карточек `photo_choice` с картинками — сейчас их почти нет, игра будет молчать.

## 5. Семена памяти и появление «Памяти» (B6, B1)
- [ ] После **верного** ответа в игре (или полностью верной «Ловли слов») — плашка со словом: «Чтобы не забыть слово, сохрани его» → **«Сохранить» / «Не сейчас»**. Слов «память» и «вкладка» в тексте нет. Не больше 3 предложений в день; слово без колоды не предлагается.
- [ ] «Сохранить» → слово улетает вниз, на панели **появляется вкладка «Память»**, над панелью на 3 с строка «Здесь твои слова не потеряются», иконка **мерцает**.
- [ ] Перезагрузить страницу: вкладка видна, мерцание осталось. Тап по «Памяти» → мерцание уходит навсегда.
- [ ] Если открыть «Память» пушем/мостиком (не тапом) — мерцание тоже гаснет.

## 6. Рассказ Пита и «Когда удобно учиться?» (C1, C2)
- [ ] Первое открытие «Памяти» → шторка с кружком Пита и **субтитрами** (текст-заглушка из `src/features/learn/memoryStoryText.js` — замените своим; озвучка появится, когда укажете `audioUrl`). Строки сменяются по таймеру, «Дальше» пропускает, в конце кнопка «Посмотреть мою память».
- [ ] Сразу после — шторка **«Когда тебе удобно учиться?»**: 9:00 / 14:00 / 20:00 / «Своё время» (поле времени + «по твоим часам сейчас HH:MM») / «Не нужно, загляну сам».
- [ ] Выбрать 20:00 → «Готово. Завтра (или Сегодня) в 20:00 придёт одно уведомление про слово». Гостю (в режиме «новенького» вы гость): «…напоминание придёт, когда войдёшь в аккаунт» — RPC не зовётся.
- [ ] Ветка уведомлений: на Android/десктопе — «Включить уведомления» / «Не сейчас»; на **iPhone в Safari** (не с экрана «Домой») — текст про экран «Домой» и кнопка «Как добавить» (слайды «Как установить»); отказ — никаких уговоров.
- [ ] Вопроса «Сколько минут в день?» после первого урока **больше нет**. Настройки «Памяти» → строка «Напоминание: 20:00 · изменить» открывает ту же шторку.
- [ ] Рассказ и вопрос второй раз не показываются (перезагрузите и откройте «Память»).

## 7. Гостевой лайк и закладка (B7)
- [ ] Тап по сердечку/закладке в ленте — **форма входа не открывается**, иконка подсвечена, переживает перезагрузку.
- [ ] Через два слайда после первого лайка — строка Пита «Пит сохранит лайки и закладки, если создашь аккаунт — это полминуты» (4 с, тап → профиль/вход). Один раз на устройстве.
- [ ] Перенос в аккаунт: проверять **не в режиме «новенького»** (там вход трогать нельзя): на чистом устройстве как гость поставить лайк, затем войти → лайк в `module_likes`, гостевые ключи очищены.

## 8. «Скажи вслух» (E)
Нужно ≥ 3 слов в памяти **с переводом** (перевод слова берётся из `word_translations` модуля). В режиме «новенького» добавьте слова: Админ → **Колоды** → «＋ В обучение» (в песочнице идёт в локальную память) — или пройдите три урока-слова.
- [ ] Вкладка «Память» → под главным действием вторичная кнопка **«Скажи вслух»** (при «Памяти пора отдыхать» — единственная). В окне слова (`LearnWordSheet`) — тоже кнопка. В итоге повторения — «Пит нашёл игру на минутку».
- [ ] Тап → слой игры. Модель Vosk не скачана → уведомление **«Нужно скачать распознавание речи (≈39 МБ)»** с кнопкой «Скачать» и полосой прогресса; системное распознавание не подставляется. Чтобы увидеть это, отключите фоновую загрузку заранее (Админ → Голос → «Остановить фоновую загрузку») или проверяйте на новом устройстве.
- [ ] Модель готова → экран «Скажи слово вслух … Слов в раунде: N» → **«Начать»** → запрос микрофона → игра: Пит показывает перевод, вы говорите слово по-английски; 10 с на слово, 90 с раунд; «Пропустить», «Не могу говорить», крестик.
- [ ] Итог «Пит нашёл N слов» со списком; у вошедшего — «+N XP» (1 XP за верное слово «к повтору», потолок 10 в день, слово оплачивается раз в день); промах → слово «к повтору» завтра (шаг не меняется). Гостю XP нет.
- [ ] Проверить на iPhone с реальной моделью: акцент, короткие слова, заглушение микрофона.

## 9. Контрольная группа и аналитика (A1)
- [ ] Админ → Аналитика: строка доли (0–50 %), под отчётом таблица **по группам** (люди, возврат D2/D7, показов, закрытий) и пометка «Мало данных — выводов нет (нужно ~1250 человек в каждой группе)».
- [ ] Поставить долю 10 %, выключить/включить «новенького» несколько раз: примерно каждое десятое устройство (хеш `anon_id` постоянный — в режиме «новенького» группа одна и та же!) не видит вопросов Пита, новых подсказок и предложений игр, но видит «Ловлю слов», «О чём диалог», «Память», рассказ и «Когда удобно». Проверить группу можно в Local Storage: `nb:pithy_prompt_group_v1`.
- [ ] Доля 0 % → все, включая уже распределённых в control, снова видят вопросы.

## 10. Напоминание по своему времени (A3) — только вошедшим, после миграций и деплоя
- [ ] Выйти из «новенького», в настройках «Памяти» выбрать «Напоминание: …» → своё время через 15 минут → в `user_profiles` появились `remind_at`, `remind_enabled = true`, `next_remind_at` (UTC по вашему поясу `tz`).
- [ ] Через ≤ 10 минут после наступления времени приходит пуш «Пит напоминает / Пора повторить слово — одна минутка» (шаблон `remind_word` в админке «Пуши»), `next_remind_at` сдвинулся на завтра. Если cron опоздал больше чем на 2 часа — пуш не шлётся, момент сдвигается.
- [ ] Ручная проверка SQL пояса/перехода на зимнее время: вставить `supabase/checks/remind_time.sql` в SQL Editor — должен завершиться без ошибки.

## 11. Разбор урока (G1)
- [ ] Канвас → Разбор → «Изменения»: новая нода — **розовая** полоска и подпись «новая», изменённая — **янтарная** и «изменена»; счётчик «N новых · M изменённых».

## Если что-то не так
- Шторки Пита не появляются: проверьте долю контрольной группы (п. 0.3), группу устройства в Local Storage, бюджет (20 с, 5 слайдов, 2 за сессию), и что в консоли нет ошибок.
- Игры не предлагаются: в колодах нет подходящих карточек (слово не в памяти, с колодой), или лимит 4 в день уже выбран (`nb:pithy_feed_choose_v1`).
- Вкладка «Память» не скрылась: в песочнице уже есть слова (переключите «новенького» заново).
- Что исправить — напишите, с какого пункта и что увидели вместо ожидаемого.
