# Этап 2 «Фразы» игры «Встряхни память»

Продолжение [CONCEPT_RACE.md](CONCEPT_RACE.md) (этап 1 «Пинг-понг» описан там). Решения владельца 2026-11-06: одна широкая лента (три дорожки съезжаются), круг 1 «Пойми» — Пит говорит смысл по-русски (намерение, не перевод; с 2026-11-07 — ситуацию `scene`, смысл остаётся кругу 2, см. «Лента и круги»), три фразы едут одна за другой, поймать верную и пропустить чужие; круг 2 «Скажи» голосом — одна фраза, бледный текст, заливка по словам; пальцами — Пит говорит фразу, по ленте три русских смысла. Единица учёта — слово (точность слова = Пинг-понг + фразы, где оно было), игра двигает уровни памяти. Минимум данных: верная всегда своя, запутыватели — дежурные фразы первых трёх модулей курса, пока своих меньше трёх; дежурные слова — из тех же фраз.

## Контракт данных
`plan.phrases = [{ id, text, key, words: [{ text, translation, level }], ru, scene, own, level, audio }]` (3…6, своя фраза урока первой), `plan.extraWords = [{ text, translation, level, due, lapses }]` (≤ 12, добор словами дежурных фраз до 6); `ru` — смысл из `app_settings.race_phrase_ru[key]` → `curricula.title_translation` → ''; `scene` — ситуация для круга 1 из `app_settings.race_phrase_scene[key]` → черновик `racePhraseSceneDefaults.js` → '' (не перевод); озвучка смысла и ситуации — `word_audio` по `transKey(текст)`; `audio` — целая фраза из `app_settings.game2_phrases` или null (читается по словам). Слушатель: `createPhraseListener({ phrases, lang, getStream, isHeld, onWord, onPhrase, onError }) → { stop, reset, setPhrases }`, `PHRASE_OK = 0.75`.

В обсуждении.


### Память: запись из игры

В финале игры (экран итога, `useRaceActs.js` сразу после `reportRace`) игра двигает уровни памяти слов: **одно событие на слово**, `reviewWord({ word, outcome, source: 'game', events: { acc, passes } })` (`raceMemory.js`: `outcomesOf` → `pushRaceMemory`). Слова идут по одному, последовательно; результат — только в журнал (`[memory] слово → outcome: step a→b (applied / не в срок)` и итоговая строка), на экране итога ничего не меняется; сбой сети финал не ломает.

Исход слова — по всем его результатам в игре (проходы A и B «Пинг-понга» с дополнительными кругами, ступени «Вершины», фразы этапа 2 — поля `phraseHits` / `phraseMisses`, когда появятся):
- всегда верно и чисто (ни промаха, ни ответа «в последний момент», ни «не то» на пилюле, дополнительный круг не понадобился) → `good`;
- верно после промаха или нечисто → `hard`;
- только промахи, зачёта ни разу → `again`;
- слова, которых в игре не было, не трогаются. Пропущенная ловушка — чистый зачёт, «поверил чужому переводу» — промах.

Шаг считает сервер по обычному правилу повторения: верный ответ раньше срока (`due_on`) шаг не двигает (`applied = false`), `again` — шаг вниз и срок завтра. Слово, которого нет в памяти, сервер не создаёт (`{ ok: false, reason: 'not_found' }`) — в журнале «не записано (not_found)». Гость — тот же `reviewWord`, он сам уходит в локальную память (`guestMemory.js`).

Когда пишем: план гонки не со стенда (`plan.source !== 'sim'` — фикстуры и JSON админки всегда `sim`) и не запрещено планом (`plan.memoryWrite !== false`); один раз за игру (повтор экрана итога и перерисовки второй раз не пишут; «Ещё раз» — новая игра).

Миграция `supabase/migrations/20261106200000_review_source_game.sql`: источник `'game'` в CHECK `review_events_source_check` и в проверке `p_source` функции `memory_review_word` (функция целиком из `20260926120000_memory_settled.sql`).
### Слух фраз
`src/features/pitrace/racePhraseListen.js` — `createPhraseListener({ phrases: [{ key, words }], lang = 'en', getStream, isHeld, wordByWord, onWord, onPhrase, onError }) → { stop(), reset(), setPhrases(phrases, { wordByWord }) }`, разбор — `racePhraseScore.js`. Только Vosk.
- Словарь Vosk — слова ВСЕХ кандидатов без повторов, поверх `createGame2Listener` (`grammarMax`: до 4 слов за заход, не больше 1600 фраз словаря; на 3–4 кандидата это обычно 2 слова за заход). Слушать начинает сразу.
- Сопоставление — `matchPhrase` по каждому кандидату, доля `ratio` — по СЛОВАМ кандидата («I'm» — одно слово). `onWord({ phraseKey, index, text })` — каждое новое совпавшее слово кандидата один раз (для заливки сегментов пилюли).
- Зачёт `onPhrase({ phraseKey, ratio, heard })`: `ratio ≥ PHRASE_OK = 0.75` и лучший однозначен — совпал полностью (второй — нет) или опережает второго на ≥ 0.25. Полное совпадение засчитывается сразу по черновику; неполное (3 из 4) — по правилам ниже: договорена (последнее слово есть) — итогом сразу или черновиком через 0,4 с; нет последнего слова — «Последнее слово»; прочее — после конца захода и паузы 1,2 с без новых слов (ученик мог не договорить). «Чисто/нечисто» решает движок по `ratio`.
- Услышанное копится между заходами 6 с (в проходе 1 «по слову» — 15 с, `JOIN_WBW_MS`) (фраза в два-три захода собирается целиком, слово на стыке не теряется). После зачёта заход закрывается, накопленное сбрасывается, слушание начинается заново. Пока `isHeld()` (говорит Пит) услышанное не учитывается.
- Общее начало («nice to … you» при кандидатах «Nice to meet you» / «Nice to see you») не засчитывается ни одному. Журнал `[phrase-ear] кандидаты … · услышал «…» · лучший «…» ratio …` — на каждый зачёт и на заход без совпадения.
- **Последнее слово** (2026-11-07, владелец: «говорю быстро — линия стоит на предпоследнем слове около секунды»). Замер реальным Vosk EN в Chromium (espeak, «nice to meet you» за 0,6–0,9 с): слово приходит в черновике через 0,23–0,45 с после звука, полное совпадение — зачёт в тот же миг. Но если последнего слова в черновике нет, заход раньше ждал авто-стопа (3,5 с без новых слов: затвор тишины не даёт эндпойнтеру Vosk закрыть заход) и ещё 1,2 с — ≈ 5 с. Теперь: черновик покрывает все слова однозначного кандидата, кроме последнего (`lastOnly`), продержался 150 мс (`LAST_HOLD_MS`), а звука нет 350 мс (`QUIET_LAST_MS`, уровень ниже `GATE_RMS`) — слушатель просит итог захода сразу (`game2.stop`); последнее слово, если было сказано, приходит в итоге — зачёт «чисто»; нет — неполное совпадение ждёт 400 мс (`SETTLE_LAST_MS`), звук в микрофоне отодвигает решение. Без слова «you» зачёт 0,75 теперь через ≈ 0,7 с после последнего черновика (было ≈ 4,9 с). Настроить эндпойнтер у `vosk-browser` 0.0.8 нельзя (в API только `setWords`). Журнал `[phrase-ear] черновик|итог «…» +N мс` — каждое новое услышанное от первого звука попытки (таймлайн на телефоне).
- **Пауза перед последним словом** (2026-11-08, замечание владельца 7: «при сказанной полной фразе пилюля не заполняется какое-то время, а потом дозаполняется»). Замер реальным Vosk EN (стенд с `createPhraseListener`, espeak по словам с паузами): при `QUIET_LAST_MS` 350 мс обычная пауза 0,45 с перед «you» считалась концом речи — итог захода просили посреди паузы, заход закрывался, «you» попадало в промежуток до следующего захода и терялось; заливка стояла на 75 %, через 1,15 с зачёт 0,75 «нечисто» доливал её — ровно картина владельца. Теперь тишина «договорил» — не меньше 650 мс и не меньше 1,5 × самой длинной паузы между словами этой попытки (медленный ученик — дольше, потолок 1,5 с), следующий заход начинается сразу (`restartMs: 0`). Фразы целиком и по словам с паузами 0,15 / 0,45 / 0,7 с и «три слова подряд, пауза 0,45, последнее» — везде «чисто», 100 % через 83–100 мс после последнего слова (CPU 1× и 4× одинаково: Vosk работает в воркере, черновики приходят ровно, пачек нет). Выдержку затвора тишины (`voskGate`, 300 мс) не удлиняли: проверка с 600 мс — эндпойнтер Vosk (0,5 с тишины) сам закрывал заход посреди фразы, слова терялись совсем. Шум (розовый, 2,5 с) черновиков не даёт, заливка 0. **2026-11-08 (v8): порог поднят до 1100 мс** — повторный замер с паузой ровно перед последним словом показал, что при 650 мс пауза 0,7 с теряет слово (итог просили на 650 мс тишины, последнее слово начиналось в промежутке между заходами ≈ 0,2 с: «where are you … from», «nice to meet … you» — нечисто 0,75); быстрый случай «сказал, а черновик слово не показал» теперь закрывает «Итог по затвору» ниже.
- **Итог по затвору** (2026-11-08, замечание владельца 1: «последнее слово будто застревает»; журнал iPhone «Where are you from»: черновики `where` +5205 … `where are you` +7988, «from» в черновике не появилось вовсе — только итогом в +9155, через 1,2 с). У `vosk-browser` 0.0.8 нет ни `setPartialWords`, ни `setMaxAlternatives`, ни настройки эндпойнтера (в воркере только `SetWords`; черновик и так приходит на каждый кусок звука ≈ 43 мс) — последнее слово иногда видно только в итоге, поэтому итог надо просить раньше. `racePhraseListen.js`: затвор тишины закрылся (≈ 300 мс после конца голоса), услышано всё, кроме последнего слова (посреди фразы заход не рвём: замер — «to» в отдельном заходе Vosk не узнаёт), а голос шёл ещё ≥ `TAIL_VOICE_MS` = 80 мс ПОСЛЕ последней смены черновика (сказанное есть, а в черновике его нет; при обычной паузе перед последним словом это от −150 до +30 мс) ИЛИ в этом заходе есть слова и у лучшего кандидата уже есть последнее слово, а не хватает середины («where you from» — ждать нечего, раньше ждали авто-стоп 3,5 с) — через `GATE_CLOSE_FINAL_MS` = 150 мс просим итог захода; голос вернулся раньше — отмена; решение по прошлым заходам ждёт этот итог (до 0,75 с). Если черновик пришёл уже после голоса (обычная пауза перед последним словом — Vosk показал всё сказанное) — затвор итог не просит, работает правило «тишина ≥ 1100 мс» выше: проверка на настоящем Vosk (espeak-ng, паузы 0,45–1,0 с) показала, что итог «по любому закрытию затвора» рвёт заход посреди паузы 0,55–0,6 с, и начало последнего слова попадает в промежуток между заходами (≈ 0,2 с) — «нечисто». Слушатель слов под слушателем фраз больше не считает заход «полным» (`expected` = `NEVER_COMPLETE`): его счёт по словам («where are are you» = 4 слова; после прошлых заходов — любое одно слово) держал затвор тишины открытым, и эндпойнтер Vosk сам рвал заход в паузе 0,7 с перед последним словом (замер CPU 4×, «from» терялось); полную фразу и так решает слушатель фраз по черновику. Журнал: `[phrase-ear] итог запрошен: затвор закрыт +150 мс, черновик «where are you», голос после черновика N мс|последнее слово есть +M мс`; взлёт — `[fill] 100 % через N мс после последнего слова, последнее слово пришло: черновиком|итогом, взлёт +M мс`.
- **Фраза договорена** (2026-11-09, журнал владельца с iPhone, v3.3.171: «Where are you from» без «are» — пилюля полная, а взлёт через 1,2 с после итога: неполное совпадение ждало `SETTLE_MS`, хотя ученик уже сказал последнее слово). `saidThrough(scores)` (`racePhraseListen.js`): у однозначного лучшего кандидата (≥ 0,75, разрыв по `pickPhrase`) услышано ПОСЛЕДНЕЕ слово (и в прошлых заходах окна 6 с), а не хватает середины — её уже не доскажут, ждать нечего. Итог захода с этим — зачёт сразу; черновик — через `SETTLE_LAST_MS` 400 мс (голос в микрофоне отодвигает: черновик ещё может достроиться до полного — тогда «чисто» сразу), итог по затвору при этом по-прежнему просим и пришедший раньше итог решает сразу; конец захода — тоже 400 мс. Заливка: последнее слово без итога ведёт кромку к `LAST_WORD_CAP` 0,97 (у самого края, не упёрлась), 100 % — только по итогу фразы, так что «полная пилюля стоит» не бывает. Замер реальным Vosk EN (espeak-ng, `vosk-model-small-en-us-0.15`, Chromium, кандидаты «where are you from» / «nice to meet you»): «where … you from» с паузами 0,5 с — зачёт через 0,44–0,47 с после конца речи (было 1,9 с), слитно «where you from» — 0,54–0,56 с (было 1,9 с); полная фраза не изменилась (по словам — до конца звука, слитно — 0,24 с). Если «from» Vosk отдаёт только итогом, а в черновике «where you» — итог приходит с авто-стопом (≈ 3,6 с после речи; было 4,8 с: 1,2 с ожидания больше нет). Журнал: `[phrase-ear] договорена: последнее слово есть, ratio 0,75 — зачёт по итогу|по черновику|по концу захода через N мс`.
- **Середины нет** (2026-11-09, продолжение «Фраза договорена»: «where … you from», «from» Vosk отдаёт только итогом — в черновике «where you», ни последнего слова, ни случая «не хватает только последнего», итог приходил по авто-стопу через ≈ 3,6 с после речи). `halfWay(scores)` (`racePhraseListen.js`): у однозначно лучшего кандидата (разрыв со вторым ≥ `PHRASE_GAP`) услышано ≥ 2 слов цели (`HALF_MIN`, или доля ≥ 0,5), последнего нет. «Итог по затвору» теперь просит итог и в этом случае — когда голос шёл ≥ `TAIL_VOICE_MS` 80 мс после последней смены черновика (сказано то, чего в черновике нет); защита от разрыва захода в обычной паузе между словами сохранена (там черновик приходит после голоса). Итог с последним словом — «договорена», зачёт сразу; ничего не добавил — ждём дальше в окне 6 с. Если «you» и «from» Vosk показал разом (слитная речь), голоса после черновика нет — такой черновик просит итог по тишине, как «без последнего слова» (≥ 1100 мс, `QUIET_LAST_MS`). Замер реальным Vosk EN (espeak-ng, `vosk-model-small-en-us-0.15`, Chromium, «from» вырезано из черновиков): с паузами 0,5 с — зачёт через 0,69–0,79 с после речи (было 3,6 с), слитно — 1,24 с (было 3,8 с); регрессия (по словам с паузами 0,5 / 0,7 / 1,0 с и «последнее слово после паузы», обе фразы, черновиком и итогом) — «чисто», времена как раньше; единичные потери «are» на паузе 0,7–1,0 с — собственный итог Vosk посреди фразы (без запроса слушателя, тот же код, что до правки). Журнал: `[phrase-ear] итог запрошен: затвор закрыт +150 мс, черновик «where you», голос после черновика N мс (середины нет) +M мс`.
- **Проход 1 «по слову»** (2026-11-09, журнал владельца с iPhone, v3.3.174, «анимация затупила при считывании»: «Nice to meet you» по слову с паузами 2,4–2,8 с — «черновик «nice to» без последнего слова, тишина 1504 мс — прошу итог», заход перезапущен посреди «meet», затем итог запрошен при ПУСТОМ черновике — «meet» потерян дважды, «nice to you» нечисто). Правила ранних итогов вынесены в `racePhraseEarlyFinal.js`. Сцена сообщает проход слушателю: `setPhrases(кандидаты, { wordByWord: pass !== 2 })`. В проходе 1: «середины нет» (`halfWay`) итог не просит ни по затвору, ни по тишине; остаётся только «не хватает ровно последнего слова» (`lastOnly`) — по тишине `quietLimit` (не меньше 1,1 с и паузы попытки × 1,5, потолок 3,5 с — `QUIET_MAX_WBW_MS`; в проходе 2 потолок 1,5 с) и по затвору (≈ 0,45 с после конца слова — в начале паузы); неполное совпадение (и «договорена») засчитывается не раньше 3 с без голоса (`SETTLE_WBW_MS`, голос отодвигает) — раньше «nice to meet» засчитывалось «нечисто» через 0,4 с после итога, пока ученик ждал подсказку «you». Проход 2 — правила v3.3.173 без изменений. **Пустой черновик** — итог захода не просим никогда (оба прохода). **Vosk молчит** — разбор по коду: это не задержка воркера, а затвор тишины (`voskGate.js`: после 300 мс тишины звук в Vosk не идёт, без звука декодер ничего не отдаёт) плюс авто-стоп захода 3,5 с, который досылает 400 мс тишины — отсюда «i am» через 3,4 с. Теперь затвор закрыт, черновик не пуст, событий Vosk нет 1,5 с (`VOSK_QUIET_MS`) — журнал `[phrase-ear] Vosk молчит N мс после голоса (черновик «…»)`; в черновике нет ни одного слова цели (недорешённый кусок вроде «i») — ещё и итог захода сразу (голоса нет). Строка `итог «…»` теперь говорит, кто закрыл заход: `(движок сам)` — эндпойнтер Vosk, `(кнопка «Стоп»)` — наш запрос, `(авто-стоп)`. Замер реальным Vosk EN (espeak, Chromium), проход 1, паузы 2,5 с и 1,6/2,8/2,0 с, три фразы × 2: было 4 из 12 «чисто», стало 11 из 12 (оставшийся промах — эндпойнтер Vosk сам закрыл заход «where» на начале «are»: тишина затвора 0,3 с + предзвук — на грани его правила 0,5 с; так было и раньше); проход 2 — без изменений (итог через 0,7 с, «where … you from» 0,7 с).
- **Журнал слуха** для телефона: `[phrase-ear] черновик «…» +N мс` (новый текст), `итог «…» +N мс` (каждый итог, и с тем же текстом), `partial без изменений «…» +N мс` (черновик Vosk пришёл, текст тот же; не чаще 500 мс — видно, что черновики идут), `черновик «…» без последнего слова, тишина N мс (порог M) — прошу итог захода`, `[gate] открыт|закрыт +N мс (rms 0,040)` — затвор тишины (закрыт — тишина не идёт в Vosk; события — `startListening(opts.onGate)` → `createWordListener({ trace: true })`).

- Список фраз плана (`plan.phrases`; нет их — фраза урока `plan.phrase`), у каждой два поля: «Смысл (круг 2)» — смысл по-русски (намерение, не перевод), пример — «скажи, что рад знакомству»; «Ситуация (круг 1)» — контекст без подсказки слов, пример — «ты знакомишься с новым человеком». Фраза без целой озвучки (`audio === null`) помечена «читается по словам».
- Сохранение — по кнопке «Сохранить» в `app_settings.race_phrase_ru` и `app_settings.race_phrase_scene` = `{ [key]: text }` (key = normText английской фразы, как `plan.phrases[].key`; пустой текст убирает ключ, ключи других уроков остаются). Пишет админ (`saveAppSetting`), читают все (`getAppSetting`).
- Озвучка — кнопка «Озвучить смыслы (ElevenLabs)»: тот же путь, что у переводов слов (`useTransVoice` → `generateWordAudio` → R2 → `word_audio`, ключ `transKey(смысл)` = `ru:…`); «озвучено» — есть запись по этому ключу. `transTexts(plan)` тоже включает `plan.phrases[].ru` и `plan.phrases[].scene`. Таблица «Озвучка Пита» — своя группа «Ситуации (круг 1)» между смыслами и переводами (id `scene:<key>`, правка — в `race_phrase_scene`). В игре Пит говорит смысл через `sayText(ru, { ru: true })`.

### Данные: план из памяти

Слой данных — `src/features/pitrace/plan/` (чистые модули, данные аргументами; движок только читает план). Источник плана `'memory'`: `buildMemoryPlan({ base, deps })` → `{ ...base, game: 'race', source: 'memory', extraWords, phrases }`; `base` — план урока (на стенде — фикстура), `deps` — данные из `loadPlanDeps()` (`racePlanSources.js`: всё параллельно, кэш 5 минут, ошибка источника — пустой источник и строка в `errors`). `normalizePlan` (`rehearsalPlan.js`) принимает `phrases` (`racePhraseNorm.js`), `memoryPlan(base, deps)` и `planFor('memory', { fixture, deps })` — то же через нормализацию.

**plan.phrases** — 3…6 фраз, без повторов по `key`:

```
{ id: '<curricula.id>' | 'plan:<key>' | 'reserve:<…>', text: curricula.title, key: normText(text),
  words: [{ text, translation, level }],  // lesson_ids.slice(1, -1) → wordKey(lesson.title); без уроков — word_translations; перевод — word_translations модуля; level — levelOfWord (нет в памяти — 0)
  ru: race_phrase_ru[key] → title_translation → '',   // смысл по-русски (круг 2); озвучка — word_audio по transKey(ru)
  scene: race_phrase_scene[key] → черновик → '',        // ситуация (круг 1); пусто — круг 1 говорит ru; озвучка — word_audio по transKey(scene)
  own: true | false, level: минимум уровней слов (нет слов — 0),
  audio: { url, duration } | null }        // app_settings.game2_phrases['rh2_phrase:' + key]; null — Пит читает по словам
```

Порядок: фраза текущего урока первой (`deps.currentId` / `base.moduleId` → модуль с той же фразой → фраза из самого плана, `id: 'plan:<key>'`, смысл — `base.translation`), затем свои — модуль начат (`fetchStartedModules`), закреплён (`phrase_memory`) или хоть одно его слово в памяти; среди своих сначала со слабыми словами (уровень ≤ 1, просрочено или с промахами), потом по уровню фразы, при равенстве — по семени (`rngFor(seed, 'race-phrases')`). Своих (с текущей) меньше трёх — добор дежурными до трёх.

**Дежурные фразы** (`raceStandbyPhrases.js`) — первые три опубликованных модуля по `created_at` по возрастанию (равные — по id), `own: false`; та, что уже в плане своей, не повторяется. Модулей меньше трёх (нет сети) — запасные фразы из слов `STANDBY_WORDS`: «Nice to meet you», «Where are you from», «Remember» (`id: 'reserve:…'`).

**plan.extraWords** — `[{ text, translation, level, due, lapses }]` ≤ 12: слова памяти (`listWordMemory`, гость — память гостя) с переводом из `word_translations` опубликованных модулей, без слов фразы плана; сначала просроченные, потом ниже уровень, потом больше промахов, при равенстве — по семени. Меньше шести — добор словами дежурных фраз до шести.

**Дежурные слова** — слова дежурных фраз плана: `extrasOf` (добор «Разгона») берёт `plan.extraWords`, затем слова фраз `own: false`, и только если их меньше шести — старый запас (`STANDBY_WORDS` и слова фикстур); `standbyWords(taken, plan)` (дополнительный круг) — слова дежурных фраз, а меньше трёх — ещё `STANDBY_WORDS`.

**Стенд**: Админ → «Голос» → «Встряхни память (стенд)» → «Настройки» → «План: фикстура / из памяти» (`RacePlanSource.jsx`, выбор помнится). «Из памяти» — сводка (слов памяти, добор, фраз — свои / дежурные; без смысла, без озвучки фразы, без озвучки смысла), перед запуском план идёт через `buildMemoryPlan`; в журнал одной строкой `[plan] источник: … · N слов памяти, добор K · M фраз (свои / дежурные) · без смысла: … · без озвучки фразы: … · без озвучки смысла: …`.

**Чего пока нет в данных**: порядка модулей (дежурные — по дате создания); `race_phrase_ru`, `race_phrase_scene` и `game2_phrases` читает только админ (ключей нет в `app_settings_public_keys`) — обычному пользователю до их добавления смысл придёт из черновика или `title_translation`, ситуация — из черновика, а фраза без озвучки (Пит читает по словам).

### Озвучка фраз целиком

- **Где**: библиотека слов `word_audio` (lang `en`), ключ `phrase:<normText фразы>` (`racePhraseAudio.phraseWordKey`). Почему не `game2_phrases`: её читает только админ, а `word_audio` — любой игрок; голос тот же, что у слов (`generateWordAudio` → edge `tts-elevenlabs` → R2). `game2_phrases` (`rh2_phrase:<key>`) остаётся запасным источником плана.
- **Как озвучить**: Админ → «Голос» → «Встряхни память» → «Озвучка Пита» → группа «Фразы целиком» (фразы текущего плана: текст, статус, длительность, «Озвучить»); входят в «Озвучить недостающие» и «Переозвучить все».
- **План**: `planContext` кладёт в `audioMap` записи `word_audio` `phrase:*` поверх `game2_phrases` (`phraseAudioMap`) → `phrase.audio`. Нет в плане — Пит ищет запись на ходу в загруженной библиотеке (`phraseAudioOf`).
- **Прогрев**: `cfg.phraseAudio` (`phraseAudioItems`) → `wordsPlan.late`: файлы фраз качаются и декодируются фоном, слот `phrase:<key>`; играет буфер, нет буфера — `<audio>`.
- **По словам** (записи нет): слова впритык — следующее стартует, когда у прежнего кончился голос (`sayText(…, { tight })`, без хвоста тишины файла), раньше на тишину в начале своего файла, но не больше `JOIN_OVERLAP_MS` (100 мс); буферы начинаются и кончаются тишиной — стык без щелчка.
- **Журнал**: `[phrase-voice] фраза «…»: целая запись` / `по словам (N)`.

### Лента и круги

**Место в игре.** Акт `phrases` идёт после «Пинг-понга» и перед итогом: в полной гонке — после прохода B, до «Вершины»; в режиме «Пинг-понг + фразы + финал» (`raceOnly.STAGES_ROUND`, по умолчанию) — перед итогом. Прежний «Пинг-понг + финал» — `PINGPONG_ROUND`, кнопка блока. Один этап — `?only=phrases` / кнопка «Фразы». Этапа нет, если фраз меньше трёх или среди них нет своей (`racePhraseData.hasPhrases`). У плана-симуляции без фраз (фикстуры админки, стенд) — фразы из `racePhraseFixture.js` (3 свои + 1 дежурная, `ru` заполнены, `audio: null`). Голосом после русского прохода B перед фразами плашка «Секунду, переключаю слух» (`phrases-sw`), фразы слушает английская модель.

**Широкая лента.** Пока идёт акт (`data-tape` на корне игры, `wordLaneTape.js`; держится и на паузе — после «Продолжить» лента сразу в своём виде, без переходной анимации), три дорожки за 0,6 с съезжаются в одну: крайние колонки `.wlLanes i` сдвигаются к средней и гаснут, разделители расходятся к краям ленты (5 % и 95 %). На выходе из этапа всё разъезжается обратно. Только transform и opacity, новых узлов нет (`word-lane-wide.css`). Конвейер медленный: по средней дорожке едет узор «нить» РОВНО со скоростью пилюль (на ленте множитель привода — скорость пилюли ступени 0,55 / 0,36 (2026-11-07…08 было 0,43 / 0,27, до того 0,55 / 0,4), а не «не медленнее конвейера»; стенд 375×812: узор 116,7 px/с, пилюля 116,3 px/с, расхождение < 1 %; до правки узор шёл ≈ 1,8× быстрее). Верный ответ подсвечивает всю ленту от кромки до кромки цветом ленты (`.wlLanes[data-win]::before`, `word-lane-lane-flash.css`), а не только среднюю колонку. Пилюля широкая (`pool.take(…, { wide: true })`): по центру, 90 % ширины, 11 % высоты, текст в две строки шрифтом `clamp(14px, 4vw, 18px)`. Тап засчитывается по всей ленте: берётся пилюля, чей центр ближе всего к середине экрана. Пит на этапе стоит по центру, уворота нет (`step.tapOnly`); «Пальцами» его сдвигает свойство `translate`. Подъём головы при речи прежний. **Две нити и верх под кнопками (2026-11-08, владелец):** нить по центру закрывала широкая пилюля — на ленте у средней колонки тот же слой узора «нить с узелками», но от 8 % до 92 % экрана и с четырьмя слоями фона (`--run-knot` / `--run-line` у левого и правого края): нити на 8 % и 92 %, по ≈ 11 px снаружи от пилюли (78 %) и внутри разделителей (5 % / 95 %), едут со скоростью пилюли (тот же `--run-y`); обрезку держит сама лента (`.wlLanes` — `contain: paint`, у средней колонки снят). Разделители на 5 % / 95 % шли сквозь «назад» и паузу и строку XP / кнопок администратора — на время акта вся лента сдвинута вниз на 80 px (`transform`, 0,6 с вместе со съездом): верх — safe + 90 px, низ за краем экрана, то есть прежний. Три дорожки «Пинг-понга» — по одной нити, верх от `--wl-top`.
**Широкая лента (пилюли и поток).** Пока идёт акт (`data-act='phrases'`), три дорожки за 0,6 с съезжаются в одну: крайние колонки `.wlLanes i` сдвигаются к средней и гаснут, разделители расходятся к краям ленты (5 % и 95 %). На выходе из этапа всё разъезжается обратно. Только transform и opacity, новых узлов нет (`word-lane-wide.css`). Конвейер медленный: по средней дорожке едет узор «нить» со скоростью пилюль. Пилюля широкая (`pool.take(…, { wide: true })`): та же капсула, что у слова (скругление 999px, рамка, тело, свечение, вертикальная заливка с кромкой, искры), только по центру, 78 % ширины (поля по 11 %, `WIDE_W`; было 90 % — 2026-11-07, владелец: «слишком широкие, нужны отступы»), 11 % высоты, текст в две строки шрифтом `clamp(14px, 4vw, 18px)`. Тап засчитывается по всей ленте: берётся пилюля, чей центр ближе всего к середине экрана. Пит на этапе стоит по центру, уворота нет (`step.tapOnly`); «Пальцами» его сдвигает свойство `translate`. Подъём головы при речи прежний.


**Чем круги отличаются (замечание владельца: «не понял отличий»).** Каждый круг открывается своей плашкой с репликой Пита, своим цветом и значком перед подзадачей, а пилюли круга 2 выглядят иначе:

| | Круг 1 «Пойми» | Круг 2 «Скажи» (голосом) | Круг 2 «Узнай» (пальцами) |
|---|---|---|---|
| Плашка | «Пойми», палец, «Тапни фразу»; рамка и подзадача цвета ленты (`--lvl2`) | «Скажи», микрофон, «Скажи сам»; акцентная (`--lvl3`) с подложкой | «Узнай», палец, «Тапни смысл»; акцентная |
| Реплика | `race_phrases_pick` | `race_phrases_say` | `race_phrases_hear` |
| Ответ | только тап, в любом режиме | только голос | только тап |
| Пилюли | три подряд, полный текст, цвет ленты (`data-mode="pick"`) | на фразу две подряд: проход 1 — пунктирная рамка с внутренним кольцом, акцентная, слова спрятаны (`data-mode="say"`); проход 2 — сплошная рамка с двумя кольцами, весь текст (`data-pass="2"`) | три подряд, смыслы по-русски на акцентной подложке (`data-mode="hear"`) |

Плашки — `raceStagesPhrases.ROUND_PLATES` → `announce(…, { look })` → `round.look` → `WordLaneTurnPlate` (`data-tone`, значок lucide `Pointer` / `Mic`, не эмодзи). Стиль кругов — `race-phrase-rounds.css` (без filter, переходы только opacity). Без озвучки реплики — только плашка с подписью.

**Круг 1 «Пойми»** (голосом и пальцами одинаково — только тап; `raceStagesPhrases.js`, `racePhraseTurns.round1Turns`). Слушатель фраз в круге не создаётся (`step.phrases.voice: false`; сцена заводит слушателя только у `mode: 'say'`), микрофон игры не трогается — голосом он остаётся открыт для круга 2. Ход есть у каждой своей фразы, в порядке плана; дежурные целью не бывают. Кандидаты хода: цель и два запутывателя с другим смыслом, свои приоритетнее дежурных, порядок по `rngFor(seed)`. Одна фраза не идёт подряд: первая пилюля хода не повторяет последнюю пилюлю прошлого.
- **Круг 1 говорит ситуацию, круг 2 — смысл** (решение владельца 2026-11-07: иначе акты слишком похожи). Пит описывает ситуацию фразы (`scene`, контекст без подсказки слов: «ты знакомишься с новым человеком», `sayText(scene, { ru: true })`), игрок тапает подходящую фразу. Ситуация есть, но не озвучена — Пит молчит, над лентой подпись с ситуацией. Ситуации нет (не заполнена и нет черновика) — fallback: как раньше, смысл `ru` (нет озвучки — подпись со смыслом). Круг 2 «Скажи» / «Узнай» — прямой смысл `ru`. Журнал: «[phrase-voice] перед ходом «…» (pick): ситуация / смысл «…»».
- Три широкие пилюли едут одна за другой на скорости 0,55: каждая в зоне чтения (≈ 22–72 % высоты) ≈ 3,5 с (50 / (26 · 0,55); 2026-11-08, владелец: «скорость слишком мала» — v3.3.155 было 0,43 и 4,5 с). Шаг задан в долях высоты: `PHRASE_GAP_PCT` = 20 % (пилюля 11 % + воздух ≈ 9 %; 2026-11-08, владелец: «расстояние ещё меньше» — было ≈ 27 %, до того 45 % «расстояние огромное»), миллисекунды — из скорости: `gapMs(speed) = 20 / (26 · speed) · 1000` ≈ 1,4 с при 0,55 (`PHRASE_GAP_MS` 1399), поэтому при смене скорости шаг не разъезжается (стенд 375×812: шаг ≈ 162 px). Скорость постоянная, как в «Пинг-понге» (решение владельца 2026-11-07: «примерно как в первом этапе, но идут фразы, а не слова, и времени на ответ нужно больше»; было 0,55 и 2,6 с — 3,5 с в зоне). Стенд 375×812 (`_stand/race/shoot-flow3.mjs`): пилюли круга 1 и «Узнай» — ≈ 116 px/с на всём пути (при 0,43 было 90–91 px/с), отыгранные и доезжающие — так же; шаг 162–165 px (20 % высоты). Журнал старта хода: `[phrases] круг 1 «Пойми» (тап фразы), ход N/M: пилюли едут, speed 0,55, gap 1399 мс`.
- **Единый конвейер.** После итога хода остальные пилюли не гаснут: они «отыграны» (`data-spent`, тише: тускнеют обводка и заливка, тело непрозрачное — узор ленты сквозь него не виден; ТЕКСТ — подпись `::after` — плавно тает совсем, opacity → 0 за 0,4 с, на слабом устройстве сразу; 2026-11-08, владелец: «верная улетает от тапа, остальные плывут дальше, но текста в них нет»; маска слов «Скажи» у упущенной остаётся бледной — она показывает всю фразу) и едут вниз, пока не уйдут за край — без взлёта, промаха и `fail`. Пит сразу переходит к следующему смыслу, а пилюли следующего хода выезжают за едущими тем же потоком: не раньше шага 20 % высоты (`gapMs(speed)`, ≈ 1,4 с при 0,55) после предыдущей пилюли на ленте, порядок сохраняется (пул — 12 пилюль). Тап по отыгранной — ничего. Журнал: «…итог верно; остальные едут: N».

- **Какая пилюля выбрана — по точке тапа** (2026-11-07, владелец: «уверен, что выбрал нужное, а показало, что неверно»). Раньше тап брал пилюлю, ближайшую к центру экрана, по положению с прошлого кадра — тап по верхней засчитывался нижней. Теперь `raceTapHit.hitPill`: прямоугольники живых пилюль снимаются в момент `pointerdown`; попал в рамку — она (перекрылись — чей центр ближе), допуск 12 px по вертикали, в зазоре между двумя — ближайшая не дальше 24 px, иначе «мимо» (кольцо в точке касания, `raceTapMiss.js`); отыгранные не выбираются. Журнал на каждый тап: `[tap] y=… x=… попал: «…» (rect …), кандидаты: …`. В тройке «Пинг-понга» выбор по дорожке (колонки 1/3 = дорожки), журнал `[tap] … дорожка N` (`raceTapTrioLog.js`).
- Верная (тап): взлёт целиком. Пит читает фразу (целая `audio` или по словам) и говорит «да, это оно» (`race_phrase_yes`).
- Чужая: дрожь 0,42 с, дальше едет отыгранной (текст тает, как у остальных; у верной текст остаётся до взлёта). Пит говорит «нет, это про другое» (`race_phrase_no`), читает верную и её смысл. Верная подсвечивается (`data-hot`) и через 0,65 с взлетает сама; если она ещё не выехала, появляется в зоне чтения.
- Верная ушла: «не успел», Пит читает её.

**Круг 2 «Скажи»** (голосом). Каждая фраза — ДВА прохода подряд (2026-11-07, замечание владельца 9: «после ответа по словам та же пилюля выезжает ещё раз, Пит: теперь повтори фразу без остановок»): `racePhraseTurns.round2SayTurns` даёт на фразу два самостоятельных хода `{ …, pass: 1 }`, `{ …, pass: 2 }` (пауза / «Продолжить» посреди прохода 2 — заново этот ход). - **Подсказка следующего слова и рывок на неверное слово** (проход 1; решение владельца 2026-11-09, ОТМЕНЯЕТ подсказку «с первого кадра пилюли» по буквам до 30 % из v3.3.170; `racePhrasePeek.js`, `racePhraseMask.nextPeek`, `racePhraseWrongWord.js`, `racePhraseNudge.js`). Смена кирпичик → текст меняет ширину — границы заливки перемеряются (`edges()` грязнеет на любой смене слова). **Тайминги.** **Ранний выезд — во всех режимах.** Круг 1 «Пойми» и «Узнай» с 2026-11-09 тоже не ждут, пока Пит договорит (владелец: «в режиме тапа нужно ещё раньше… когда Пит закончил говорить задание, первая пилюля уже должна быть на 100 % видна»; журнал iPhone: реплика 2116 мс кончилась в 56.30, «пилюли едут» — в 56.39, к концу реплики экран пуст): на `pre` первая пилюля (кандидат 0 — порядок уже перемешан, это не всегда цель) выезжает с точки `earlyAtMs` так, чтобы к концу реплики центр был на 22 % — широкая пилюля 11 % высоты, верх на 16,5 %, ниже затемнения (14 %, в гонке 7 % + safe-area) с запасом; вторая и третья — за ней ровно через путь `gap` (`at`/`lastSpawn` сдвинуты на `atMs`: не пачкой и без лишнего ожидания); места нет (за едущими прошлого хода или доезжающими прошлого круга, `pool.tail`) — обычный поток, журнал «пилюли едут (места за едущими нет — первая через gap)». Сразу после `pre` голосовая цепочка может ещё ждать, пока Пит договорит прежнее (`pitLeft` = 300 мс, длина реплики не известна) — тогда ход ждёт, пока реплика зазвучит (`pitLeft` > `EARLY_SURE_MS` 400), и выезжает с её длиной. Тап засчитывается сразу, в том числе во время реплики. Без реплики (подпись вместо голоса, или так и не зазвучала) — по-старому: 250 мс и «пилюли едут» из-за края. Стенд (`?ask=tap&only=phrases&meaning=1`, 375×812): реплика 2398 мс, старт с −12 %, к концу реплики первая пилюля целиком на экране (верх 152 px при затемнении до 57 px, центр ≈ 24 %), вторая — на шаг выше. В «Узнай» по словам (нет целой записи) `pitLeft` сразу после `pre` знает только первое слово — пилюля в зоне чуть позже конца фразы. Журнал: `[phrases] круг 1 «Пойми» (тап фразы), ход 1/3: пилюля выезжает вместе с репликой Пита (2116 мс) с −7 % высоты, speed 0,55, gap 1399 мс`. **«Скажи» (оба прохода)** так с 2026-11-08 (2026-11-08, замечание владельца 3: «пилюля уже должна успеть выехать к моменту, когда Пит закончит говорить задание»): пилюля выезжает на том же `pre`, вместе с началом реплики (смысл / `race_phrase_again`), со стартовой точки, от которой к концу реплики (сколько Пит занят сразу после `fx.pre`) её центр у верха зоны чтения 22 % — не ниже 8 % (из-под верхнего затемнения, как демо) и не ближе `gap` за едущей впереди (`racePhraseEarly.earlyAtMs`; места нет — выедет обычным потоком). Стенд (`?meaning=1`, реплика 2,26 с): появилась с центром 6,7 %, к концу реплики — 22,6 %. Слушатель включён с выезда; речь Пита он не берёт — окно речи (`isHeld` = `gameMicHold`, по умолчанию дорожка микрофона на это время выключена), а реплики перед «Скажи» русские. Фраза, которую Пит читает по-английски после промаха / «не успел», звучит в паузе `after`, а новый ход сначала зовёт `setPhrases` + `reset()` слушателя (до реплики) — накопленное, в том числе прошлые заходы в окне 6 с, забыто (тест). **Единый конвейер между кругами** (2026-11-07, владелец: «когда предпоследний этап закончен, его пилюля должна просто уехать, а не исчезнуть, и это не должно блокировать Пита»). Раньше при смене ступени (круг 1 → плашка круга 2, круг 2 → итог) уборка сцены (`useWordLanePills`) отдавала в пул все пилюли (`pool.giveAll`) — ещё едущие отыгранные пропадали посреди экрана. Теперь сцена, чей круг кончился (`fx.finished`), в `stop()` отдаёт едущие пилюли на доезд (`pool.coast`, `wordLaneCoast.js`): у пилюли остаётся её полёт (та же анимация, та же скорость) и `data-coast`, у края (`EXIT_Y`) она уходит в пул; маска «Скажи» уходит вместе с ней. Новый пул следующей сцены доезжающие не берёт, а первая пилюля круга 2 выезжает не ближе `gap` за последней доезжающей (`pool.tail`). Стоп посреди круга (пауза, перезапуск) — без доезда, как раньше. **События.** Сцена (`racePhraseScene.js`) отдаёт директору `win` / `miss` / `fail`, итог хода — в `rep.res`. Директор (`useRaceActs`) пишет событие `{ t: 'phrase', phraseKey, round, ok, late, confusedWith, ratio, clean }` в `s.phrases` (`raceStatePhrases.js`), голос Пита ведёт `racePhraseVoice.js`. Журнал: `[phrases] круг 1 «Пойми» (тап фразы), ход N/M: цель «…» кандидаты «…» | «…» | «…» итог верно / спутал с «…» / не успел` (круг 2 — «Скажи» (голос) или «Узнай» (тап смысла)); итог: `[race] итог: слабая фраза «…», спутал с «…», круг 2 ✓/✗`.

**Результаты.** Точность слова (`raceAccuracy.js`) — среднее по проходам «Пинг-понга» и по фразам, где слово было; вклад фразы: чисто 1, нечисто 0,6, промах или «не успел» 0. У слова в расшифровке добавка «во фразе Nice to meet you спутал». Слова фраз, которых не было в «Пинг-понге», тоже в списке итога. На слове итога (`weak` и `words`) — поля `phraseHits` / `phraseMisses` (их читает `raceMemory.outcomesOf`). Итог показывает строку «Фразы N/M» и блок «Слабые фразы» под словами: фраза, смысл, с чем спутал, круг 2 ✓ / нечисто / ✗ и «подряд ✓ / с паузами / нечисто / ✗» (проход 2, `RacePhrasesWeak.jsx`).
- **Два прохода «Скажи» в результатах.** «Фразы N/M» считает ходы — оба прохода, каждый как ход (у фразы 2 хода круга 2), точность слова — среднее по всем ходам со словом (проход 2 «с паузами» — 0,6, как нечисто). Слабая фраза — проход 1 или 2 не «чисто» (`phraseSummary`: `r2` — проход 1, `p2` — проход 2). Память слов (`raceMemory.outcomesOf`): фраза «Скажи» — ОДНА единица по двум проходам (`racePhrasePasses.passOutcome` → `phraseUnits` → `phraseHits` { hit, miss, unclean }): проход 1 промах / fail — промах (again), проход 2 не «чисто» (или проход 1 нечисто) — зачёт, но нечисто (`phraseUnclean` → hard), оба чисто — зачёт (good); круг 1 и «Узнай» — по ходу, как раньше.

**Слушатель.** Сцена берёт `createPhraseListener` из `racePhraseListen.js` через `racePhraseListener.js` (английская модель, игровой микрофон, окно речи Пита по умолчанию). Тесты и стенд подставляют `racePhraseListenStub.js` (`setPhraseListener`), речь подаёт драйвер: `window.__phraseSay('nice to meet you')` (черновиком — `window.__phraseDraft`). Слушатель есть только у круга «Скажи». **Фраза Пита целиком — тоже окно речи** (2026-11-09, журнал владельца v3.3.174: после «не успел» Пит читал «I'm trying to learn» целой записью, `mic-hold` не включался — слушатель распознал её из динамика с ratio 1,00): `racePhraseVoice` открывает `gameMicHold.holdFor(длина записи)` для целой записи, как у реплик и слов Пита (по словам — `sayText(…, { hold: true })`).

**Реплики для озвучки.** `race_phrases` — «теперь фразы, сначала выбирай, потом говори» (голосом, плашка «Фразы»); `race_phrases_tap` — «теперь фразы, сначала выбирай фразу, потом её смысл» (пальцами); `race_phrases_pick` — «я описываю ситуацию, а ты тапни фразу, которая подходит» (плашка круга 1); `race_phrases_say` — «а теперь скажи её сам, я подскажу смысл, а слова спрятаны» (плашка «Скажи»); демо на живой пилюле — `race_demo_1` «главное начать, смотри», `race_demo_2` «затем второе», `race_demo_3` «потом третье», `race_demo_more` «и так до конца», `race_demo_go` «теперь ты» (`race_phrases_demo` v3.3.154 удалена); проход 2 «Скажи» — `race_phrase_again` «теперь повтори фразу без остановок», `race_phrase_pauses` «хорошо, только без пауз»; `race_phrases_hear` — «теперь я говорю фразу, а ты тапни, что она значит» (плашка «Узнай»); без озвучки — только плашки; `race_phrase_yes` — «да, это оно»; `race_phrase_no` — «нет, это про другое».
