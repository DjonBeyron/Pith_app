# Маскоты: кот Пит, кошки Кетти и Мия (конструктор персонажей)

> **Имена (решение владельца, 2026-10-31):** новая серая кошка (`build_gray_cat.py`, файлы `gray_cat_*`) — **Мия**; прежняя «Мия» (`build_girl.py`, `mia.json`, скин `mia`) переименована в **Кетти**.
> Технический id скина `mia` в коде и данных остаётся за Кетти (он записан в сохранённых сценах); в тексте ниже «Мия» там, где речь о `build_girl.py`, — это Кетти. Новая Мия пока не подключена к конструктору сцен.

Источник — файл дизайнера `source/cat.ai` (слои: ТУЛОВИЩЕ / ГОЛОВА / ГЛАЗА ОТКРЫТЫ / ГЛАЗА ЗАКРЫТЫ). Из него `run.sh` собирает всё остальное; готовая демонстрация лежит в
`public/mascot/index.html` (на тестовой ветке: `/mascot/`).

## Что получается
- **Пакет персонажа** (`pack_boy.json`, `pack_girl.json`): три слоя (хвост / тело / лицо), таблица из 9 форм рта и **состояния мимики**. Состояние = глаза + брови + декор
  (румянец, пот, сердечки) + рот в покое + наклон головы + реакция зрачка. Рантайм (`story_template.html`) подставляет разметку состояния в контейнеры `.ey`, `.brows`, `.dc`,
  поэтому в DOM всегда один набор глаз.
- **Кот Пит:** обычное, «делает вид», «отводит взгляд», «влюблён» (сердечки в зрачках пульсируют), блаженный.
- **Кошка Кетти (прежняя Мия):** обычное, «пафос», «стерва» (ухмылка), «закатила глаза», презрение, «увлечена» (зрачок-щель расширяется).
- **Реакция зрачков и дополнительная мимика** — два флажка на странице (и параметры `?pr=0`, `?em=0`). **Lite-режим** для слабых устройств (`?lite=1`, по умолчанию автоопределение):
  хвост в покое неподвижен, без дыхания и пульса сердечек.
- История (`story_script.json`): реплики с озвучкой и **окна состояний** (`line`, `who`, `state`, `from`, `to`) — по ним мимика меняется в нужные моменты; смена маскируется морганием.

## Как собрать заново
`WORK=/tmp/mascot-work bash scripts/mascot/run.sh` (нужны python3 с pymupdf, fonttools, skia-pathops и node 22). Озвучка отдельно: `python3 tts_story.py <work>` (Kokoro + Rhubarb, см. шапку файла),
готовый `story.json` передаётся через `STORY=…`.

## Файлы
| Файл | Роль |
|---|---|
| `export_layers.py`, `build_rig.py`, `finalize_rig.mjs` | .ai → риг кота (слои, 9 форм рта, хвост) |
| `optimize_rig.py`, `merge_markup.py` | облегчение: запечь клипы и transform, склеить фигуры одного стиля |
| `fix_paw.py` | палец на правой задней лапе |
| `build_girl.py` | кошка Кетти (прежняя Мия) из рига кота: цвет, форма головы, лицо, глаза, украшения, хвост, лапки; состояние — переменная `EXPR` |
| `export_sprites.mjs` | Пакеты → спрайты конструктора сцен `src/features/scene/v2/sprites/mascot/{kit,mia}.json`: хвост в начало координат основания, посадка в коробку 200×240, чистка чисел |
| `make_packs.py` | пакеты персонажей и состояния |
| `tail.mjs` | кинематика хвоста (профили `boy` / `girl`) |
| `story_template.html`, `make_story.mjs` | страница-история: фон из спрайтов проекта, рантайм состояний, зрачков, рта, хвоста |
| `tts_story.py`, `story_script.json` | озвучка и разметка рта, текст реплик и окна состояний |

## Цифры (замер: Chromium, замедление CPU ×4 / ×6; реальный Samsung A50 пока не мерили)
Сцена пары 246 узлов (бюджет 250), 60 кадров/с при ×4 и ×6. Кот 61 узел, кошка 84 узла (было 68 и 115). Тело и лицо двигаются CSS-трансформом (отдельные слои), перерисовывается
только хвост и лицо при смене рта/моргании.

## В конструкторе сцен (`src/features/scene/v2`)
Маскоты подключены как скины персонажа: `characters.a.skin = "kit" | "mia"` (+ `pupilReaction`, `extraFace`, по умолчанию включены), лицо реплики — `face` (говорящий) и `react` (слушающий). Рисунок — `sprites/mascot/*.json`
(разбор разметки `markupTree.js`, дерево `mascotSprite.js`, рот `mascotMouth.js`), общие классы анимаций `cat-tail / cat-body / cat-head / cat-eyes` из `scene-v2-cat.css`. После правок рисунка: `run.sh` (или только `node export_sprites.mjs <work>`).
Шаблон «Пит и Мия: знакомство» — `demoMascotScene.js`.

Усы Пита — один контур из двух горизонтальных отрезков в голове; `export_sprites.mjs` (`markWhiskers`) ставит на него класс `wh`, и «живой Пит v2» (`scene-v2-pit.css`, флаг animV2) приподнимает их при речи. Новых узлов нет; у Мии усов в рисунке нет.

## Новая Мия (серая кошка по чистому образцу, 2026-10-31)
Не подключена к конструктору сцен, собирается отдельно: `python3 build_gray_cat.py <папка>` → `gray_cat.json` (спрайт в формате маскотов) и `gray_cat.svg`. Образцы: `source/gray_ref.webp` (голова, лицо, украшения) и `source/gray_ref2.webp` (чистый — тело, лапы, хвост).
| Файл | Роль |
|---|---|
| `vec_trace.py` | векторизация по картинке (маска → контур → кривые Безье), оси тонких линий, преобразования путей |
| `gray_cat_regions.py`, `gray_cat_details.py` | голова, глаза, мордочка, уши, усы, бантик, ошейник — с прежнего образца |
| `gray_cat_body.py` | тело, лапы, хвост — с чистого образца (обводка сплошной областью, хвост линией по оси) |
| `gray_cat_faces.py` | шесть лиц из `mia.json` (Кетти): веки, взгляд, брови под глаза Мии |
| `gray_cat_demo.py`, `gray_cat_video.py`, `gray_cat_video_page.html` | превью по формам рта и лицам; плеер «Мия и Пит рядом на одной раскадровке» (покадрово) |
