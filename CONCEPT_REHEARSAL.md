# Репетиция с Питом — концепция урока-игры (2026-10-29, черновик на обсуждение)

Что это: одна фраза за ~90 секунд проходит путь «вспомнил слова → услышал ритм → собрал с конца → сказал без текста →
записал дубль и сравнил с диктором». Пит — тренер актёров: не учитель и не экзаменатор, а тот, кто готовит к сцене.
Движок — текущая игра «Повтори за диктором» (`src/features/player/modules/rotate-phone/`), сценарий — новый слой поверх
неё. Данные на этом этапе **симулируются** (фикстура «память человека»), вкладка «Память» подключается позже
(`PLAN_REHEARSAL.md` — правило выбора фразы и этапы).

## 1. Исследования → правила дизайна
| Факт из исследований | Что это даёт игре |
|---|---|
| **Эффект проговаривания** (production effect): сказанное вслух помнится лучше прочитанного | Каждый акт заканчивается голосом, а не тапом. Тап — только там, где голос ещё нечем проверить |
| **Припоминание сильнее повторного чтения** (retrieval practice) | Текст подсказки убирается как можно раньше: акт 1 — по переводу, акт 4 — без текста. Промах — не штраф, а сигнал «это и надо тренировать» |
| **Shadowing / имитация просодии**: ритм и ударения перенимаются с голоса, не с текста | Акт 2: диктор ElevenLabs с таймингами слов, ударные слова пульсируют, человек повторяет «тенью» |
| **Обратное наращивание** (backchaining): фраза собирается с конца, конец всегда уверенный | Акт 3: [2] → [1,2] → [0,1,2]. Конец фразы звучит чаще всего — это и есть «выход со сцены» |
| **Куски речи** (chunking), 3–4 единицы в рабочей памяти | Три дорожки = три куска, не слова. Длиннее фразы режутся автором на куски |
| **Чёткая артикуляция** («как для сцены») понятнее и лучше запоминается | На последней ступени сборки Пит просит «чётко, для последнего ряда», потом «обычно» — контраст слышен самому человеку |
| **Мгновенная конкретная обратная связь** (ELSA, Duolingo Speak) — работает, если указывает на одно измеримое | Пит даёт ОДНУ заметку за сессию и только по тому, что измерено: пропуск, порядок, темп, паузы, громкость |
| **Зеркало своего голоса**: сравнение с образцом — главный инструмент актёрского коуча | Акт 5: дубль записывается и играет после диктора; сравнение прямо на дорожках: две ленты пилюль, Пит сверху и ты снизу |
| **Желательные трудности** + **короткие сессии**: ~90 с с нарастающей сложностью удерживают внимание | Пять актов, каждый короче 30 с, сложность растёт, никаких повторов ×3 подряд |
| **Внешняя награда вытесняет интерес**, если велика | XP настоящий, но с потолком, как в «Скажи вслух»; главная награда — услышать себя рядом с диктором |

## 2. Персонаж: Пит-тренер
- Говорит от первого лица, коротко, по делу, без оценок личности («не получилось слово», не «ты ошибся»).
- Метафора сцены: разминка, читка, прогон, без текста (off-book), дубль, просмотр.
- Одна реплика на событие, не чаще раза в 6–8 с; пока человек говорит — молчит (микрофон, режим «закрывать микрофон»).
- Стиль реплик — как легенда уроков (переписка с другом): коротко, часть с маленькой буквы, без «Верно!/Отлично!», без терминов и пола ученика; озвучиваемые — без смайликов, эмоция словами. Для озвучки ElevenLabs в текстах нет точек, многоточий, восклицательных знаков и тире (— и –), только запятые и «?». Тексты — решения владельца (2026-10-31), v3.3.82; все в `rehearsalLines.js`. Вариантов нет: у старта и итога два текста по номеру запуска в одном тапе («первый раз / ещё раз»), у сборки (`rh_build`, `rh_clear`) прежние по три случайных, у остальных один.

| Момент | Реплика Пита (v3.3.82, решения владельца) |
|---|---|
| Старт, первый раз (`rh_start`) | «Повторим то, что учили, и прокачаем произношение» |
| Старт, ещё раз (после «Ещё минутку?», `rh_start_b`) | «Окей, возвращаемся к знакомым словам и улучшим произношение» |
| Акт 1, старт | «давай разомнёмся, я показываю перевод, а ты говоришь слово по-английски» → отсчёт тремя нотами → первое слово |
| Акт 1, промах | «Опа, кажется, слово немного забылось, повторим завтра» |
| Акт 2 | «Сейчас скажу фразу целиком, следи за подсветкой и повтори в том же ритме» |
| Акт 3, старт | «Собираем фразу с конца, так конец звучит увереннее всего» (и прежние `_b`, `_c`) |
| Акт 3, последняя ступень | «А теперь чётко, как для последнего ряда» → всегда второй «И ещё раз, только расслабленно, будто болтаешь с другом» |
| Акт 4 | «Ну-ка, по памяти, я подскажу, если застрянешь» |
| Акт 4, застрял | голос «Начни с» (`rh_blind_hint_pre`), затем слово из библиотеки слов; подпись на экране «Начни с {word}» |
| Акт 4а, «Различи» | «Теперь на слух, какое слово я сказал?» |
| Акт 5, запись | плашка «Дубль» → отсчёт тремя нотами → «поехали» → запись |
| Акт 5, просмотр | «Послушаем по очереди и сравним произношение, сначала я, потом ты»; дорожки плавно останавливаются, на них появляется сравнение (v3.3.86) |
| Заметка (одна из) | «Ты быстрее меня на треть — это нормально, но „trying“ потерялось.» / «Пауза перед „to learn“ длиннее, чем у меня. Склей.» / «Порядок верный, темп мой. Чисто.» |
| Финал, первый раз (`rh_done`) | «Рад, что мы потренировались вместе, хочешь ещё?» |
| Финал, ещё раз (второй и далее, `rh_done_b`) | «Здорово получилось, с каждым разом всё увереннее» |

Отсчёт тремя нотами (до — ми — соль, пауза 0,5 с, как перед стартом в гонках; `rehearsalCountdown.js`, звук — игровой AudioContext) играет перед разминкой (после реплики Пита) и перед дублем (после плашки «Дубль», до «поехали»); в режиме «тап вместо речи» тоже. Номер запуска — `plan.run` (0 в первом плане тапа, «Ещё минутку?» даёт +1; «Игра заново» из HUD и шлифовка одного акта — первый запуск).

## 3. Сессия: пять актов, ~90 с
Фраза дня: `I'm | trying | to learn` (3 куска), перевод, озвучка ElevenLabs с таймингами слов, 2 слова «к повтору»
(`trying`, `learn`), у `learn` двойники `earn` и `lean` из промахов. Разминка — по всем словам фразы (`I'm`, `trying`, `to`, `learn`), «к повтору» первыми. Время — ориентир, акты пропускаются по правилам ниже.

| # | Акт | Цель | Механика на дорожках | Ввод | ~с |
|---|---|---|---|---|---|
| 0 | Заставка | Настроить | Фраза падает сверху, перевод под ней, три дорожки открываются | — | 4 |
| 1 | **Разминка** | Припомнить слова | По одному слову: над дорожкой перевод, пилюля едет, человек говорит слово. Участвуют ВСЕ слова фразы (решение владельца, v3.3.85): «к повтору» первыми (самое просроченное первым), остальные слова фразы после них вперемешку по семени; повторы слов фразы схлопнуты. У слова без карточки перевода нет — дорожка без подписи, подсказка «не успел» — само слово | Vosk, словарь: слова фразы + двойники | ~3 с на слово: 15 для фразы из 4 слов (для длинной фразы растёт; потолок 12 слов) |
| 2 | **Читка** | Ритм, ударения | Диктор говорит фразу один раз, слова подсвечиваются по таймингам, ударные пульсируют крупнее. Затем человек повторяет «тенью» один раз с той же подсветкой-метрономом | Vosk, вся фраза | 12 |
| 3 | **Сборка с конца** | Порядок, уверенный конец | Ступени [2] → [1,2] → [0,1,2]: диктор 1 раз, человек 1 раз (промах — ступень ещё раз, не больше одного повтора). На последней ступени: «чётко» → «обычно» (две пилюли) | Vosk, словарь ступени | 25 |
| 4 | **Без текста** | Припомнить целиком | Подписи кусков убраны, перевод тоже. Фраза 2 раза. Застрял (3 с тишины) — Пит подсказывает первое слово, подпись куска на 2 с | Vosk, вся фраза | 15 |
| 4a | **Различи** (если есть двойник) | Развести похожие | Диктор: «learn» — на дорожках `learn / earn / lean` без подписей → тап по услышанному → сказать слово. ВСЕГДА три дорожки (решение владельца, v3.3.85): слово и два других — двойники, а если их меньше двух, нехватку добирают слова фразы; верное слово на случайной дорожке (по семени), во второй подсказке на другой | тап + Vosk (словарь из тройки) | ≤ 12 |
| 5 | **Дубль и зеркало** | Услышать себя | Отсчёт, запись фразы целиком (MediaRecorder из потока игры). Сравнение прямо на дорожках, отдельного окна нет (решение владельца, v3.3.86): после дубля дорожки плавно останавливаются сами, на них две ленты пилюль — верхняя Пит, нижняя ты, кусок i на дорожке i (цвет дорожки, подпись «Пит» / «Ты» на самой пилюле, подписи кусков над дорожками как обычно); у Пита пилюли залиты полностью, у тебя по измерениям (кусок сказан — залита, пропущен — пустая с полосками промаха). Через 0,4 с после остановки сам (и по кнопке «Сравнить» / «Ещё раз») играет диктор, потом дубль, звучащий кусок светится (пилюля и вспышка дорожки). Одна заметка Пита — подписью над дорожками, «Дальше» ведёт в итог | запись | 25 |
| 6 | Итог | Закрепить | Фраза, перевод, темп (×1,2 к диктору), заметка, XP, «Ещё минутку?» | тап | — |

### Правила пропуска и сокращения
- Нет озвучки фразы → акт 2 без подсветки ударений (голос системы, без таймингов), зеркало без подсветки кусков диктора по словам (тайминги из длин кусков библиотеки).
- Нет Vosk → игра не стартует (как сейчас): на экране уведомление «Нужно скачать».
- Слово из акта 1 промахнулось дважды → в акте 3 его ступень получает подпись-подсказку даже на «без текста».
- Больше 3 промахов к акту 4 → акт 4 один раз вместо двух, акт 4a пропускается, зеркало остаётся (это главное).
- Фраза из одного куска (слово) → акты 1 и 3 схлопываются в «слово ×2», акт 4 — слово по переводу, зеркало — слово (две пилюли на средней дорожке).

### Что измеряем (только это и попадает в заметку)
| Измерение | Откуда | Заметка |
|---|---|---|
| Пропуск / лишнее слово | Vosk final + `analyzeTargets` | «„trying“ потерялось» |
| Порядок кусков | seq ступени | «„to learn“ прозвучало раньше „trying“» |
| Темп относительно диктора | длительность дубля / длительность озвучки (тайминги) | «быстрее меня на треть» |
| Паузы между кусками | тайминги слов Vosk (`stats.words`) против таймингов диктора | «пауза перед „to learn“ длиннее» |
| Громкость | RMS дубля против RMS озвучки (нормализованной) | «тише, чем нужно для сцены» |
Качество звуков не оцениваем — Vosk этого не умеет; Пит об этом не говорит.

### XP и память (симуляция сейчас, RPC позже)
- За сессию: +1 XP за слово «к повтору», сказанное верно в акте 1 или 4; потолок — общий с «Скажи вслух» (10 в день).
- Слово с промахом → `due_on = завтра`, шаг не меняется; без промахов → обычный шаг лесенки.
- Фраза → `phrase_memory.consolidated_at = сегодня`; одна фраза не чаще раза в 3 дня.
- Сейчас: всё пишется в `rehearsalSim` (память сессии браузера, видно в журнале отладки), ничего на сервер.

## 4. Данные: интерфейс плана и симуляция
```
RehearsalPlan {
  phrase: 'I'm | trying | to learn', translation: 'Я пытаюсь учиться', lang: 'en-US',
  chunks: ['I'm', 'trying', 'to learn'],
  words: [ { text:'trying', translation:'пытаюсь', due:true, lapses:1, confusers:[] },
           { text:'learn',  translation:'учиться', due:true, lapses:2, confusers:['earn','lean'] } ],
  stressed: [1, 2],                 // ударные куски для читки (пока вручную в фикстуре; позже разметка в редакторе)
  audio: { phrase: { url, timings:[{word, start, end}] } | null, words: lib },  // phrase_audio ElevenLabs | библиотека слов
  source: 'sim' | 'memory' | 'node'
}
```
- `rehearsalFixtures.js`: 3–4 готовых плана (три куска с двойником; два куска без озвучки фразы; одно слово; фраза без
  слов «к повтору») — переключатель в Админ → «Голос» → «Тест игры» → «Репетиция (симуляция)», JSON можно править.
- Поставщик плана — одна функция `planFor(source)`: сейчас фикстура, потом `wordMemory`/`phraseMemory` (этап 1 плана) и
  нода `rotate_phone` (автор задал фразу сам). Сценарий от источника не зависит.

## 5. Как это ложится на движок
- Сейчас: рецепт (`wordLaneRecipe.js`) → стадии (`wordLaneStages.js`) → директор (`useWordLaneFlow.js`) → движок пилюль.
- Новое: `rehearsalRecipe.js` строит стадии актов из `RehearsalPlan` (тот же формат стадий + новые типы):
  `warmup` (слово по переводу — пилюля в дорожке слова, цель — слово), `read` (диктор с подсветкой по таймингам, затем
  повтор), `build` (есть), `blind` (есть, с подсказкой первого слова), `discern` (есть, новый источник запутывателей),
  `take` (запись), `mirror` (сравнение на дорожках), `summary`.
- Директор получает план вместо `cfg` ноды; реплики Пита — из таблицы выше по событиям (`useCatLines` уже так работает).
- Зеркало: `MediaRecorder` на `getGameMic()`-потоке, запись в памяти; сравнение рисуется на дорожках игры (сцена `mirror` движка пилюль `wordLaneMirrorScene.js` по раскладке `mirror/mirrorCompare.js`, кнопки и заметка — `mirror/MirrorCompare.jsx`, проигрывание — `useMirrorPlayback.js`; отдельного экрана `WordLaneMirror` с v3.3.86 нет); темп и паузы — из
  `stats.words` слушателя (Vosk отдаёт тайминги слов) и `timings` озвучки.
- XP/память: `rehearsalResult.js` считает итог по журналу актов; поставщик записи — симуляция (сейчас) / RPC (потом).

## Вопросы владельцу (закрыты, оставлены для истории)
1. Повторы: в сборке 1 раз диктор + 1 раз человек (вместо ×3). Ок, или оставить ×2 на последней ступени?
2. Акт «Читка» с подсветкой ударений — в первой версии, или сначала без него (акт 2 = просто послушать)?
3. Зеркало в первой версии или после актов 1–4? (Это самый дорогой акт: запись, сравнение на дорожках, заметки.)
4. «Чётко / обычно» на последней ступени — две пилюли подряд с разными подписями. Не перегруз?
5. Длина: 90 с с одной фразой, затем «Ещё минутку?». Или сразу две фразы по 60 с?
6. Тексты Пита выше — править здесь, в таблице.

## 7. Порядок работ (2026-10-29, «поехали»)
1. `RehearsalPlan` + фикстуры + переключатель в «Тесте игры»; сценарий всех актов 0–4a, 6 на движке (читка по кускам, чётко/обычно с ярлыком).
2. Параллельно: дубль и зеркало (запись, сравнение на дорожках, измерения, одна заметка Пита) как модуль с узким интерфейсом; затем встраивание актом 5.
3. Озвучка фраз ElevenLabs с таймингами (`phrase_audio`, миграция, кнопка в админке) → читка с ударениями, зеркало по словам диктора.
4. XP и память — симуляция → RPC; подключение к вкладке «Память» (этап 1 плана).

## 8. Случайность внутри актов (решение владельца, 2026-10-30)
Порядок актов фиксированный (разминка → читка → сборка с конца → без текста → различи → дубль и зеркало → итог): он несёт педагогику.
Разнообразие — ВНУТРИ актов, по правилам, с семенем от даты и фразы (одна сессия воспроизводима, разные дни разные):
- **Разминка**: слова — все слова фразы; первое — самое просроченное, потом остальные «к повтору» вперемешку, потом остальные слова фразы вперемешку; дорожка слова — случайная из трёх (не всегда своя).
- **Читка**: одна из 2–3 реплик «зачем» (`rh_read_why` варианты a/b/c).
- **Сборка с конца**: ступень «чётко / обычно» — случайно, какая первая; при двух кусках иногда [1] → [0,1], иногда [0] → [0,1].
- **Без текста**: порядок двух проходов и какая подсказка первой (первое слово / перевод куска) — случайно.
- **Различи**: три дорожки всегда; какие два других слова (двойники, при нехватке — слова фразы) и на какой дорожке стоит верное слово — случайно; ряд дорожек перемешан.
- **Дубль и зеркало**: порядок «сначала я, потом ты» фиксированный; заметка Пита при равных измерениях — случайная из вариантов одного смысла.
- **Реплики**: у каждого ключа 2–3 варианта текста, выбор случайный, повтор подряд запрещён.
Не случайно никогда: первое слово разминки (самое «просроченное»), структура ступеней сборки, зеркало последним.
Предложение на потом (не решено): короткий сценарий для повторной встречи с фразой и 30-секундный для уверенной.
