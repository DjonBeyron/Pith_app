# Репетиция с Питом — концепция урока-игры (2026-10-29, черновик на обсуждение)

Что это: одна фраза за ~90 секунд проходит путь «вспомнил слова → различил на слух → собрал с конца → услышал ритм →
сказал без текста → записал дубль и сравнил с диктором» (порядок актов с v3.3.87). Пит — тренер актёров: не учитель и не экзаменатор, а тот, кто готовит к сцене.
Движок — текущая игра «Повтори за диктором» (`src/features/player/modules/rotate-phone/`), сценарий — новый слой поверх
неё. Данные на этом этапе **симулируются** (фикстура «память человека»), вкладка «Память» подключается позже
(`PLAN_REHEARSAL.md` — правило выбора фразы и этапы).

## 1. Исследования → правила дизайна
| Факт из исследований | Что это даёт игре |
|---|---|
| **Эффект проговаривания** (production effect): сказанное вслух помнится лучше прочитанного | Каждый акт заканчивается голосом, а не тапом. Тап — только там, где голос ещё нечем проверить |
| **Припоминание сильнее повторного чтения** (retrieval practice) | Текст подсказки убирается как можно раньше: акт 1 — по переводу, акт 5 — без текста. Промах — не штраф, а сигнал «это и надо тренировать» |
| **Shadowing / имитация просодии**: ритм и ударения перенимаются с голоса, не с текста | Акт 4 (читка, после сборки): диктор говорит фразу, слова заливаются зелёным в такт его голосу, человек повторяет «тенью» с той же заливкой |
| **Обратное наращивание** (backchaining): фраза собирается с конца, конец всегда уверенный | Акт 3: [2] → [1,2] → [0,1,2]. Конец фразы звучит чаще всего — это и есть «выход со сцены» |
| **Куски речи** (chunking), 3–4 единицы в рабочей памяти | Три дорожки = три куска, не слова. Длиннее фразы режутся автором на куски |
| **Чёткая артикуляция** («как для сцены») понятнее и лучше запоминается | На последней ступени сборки Пит просит «чётко, для последнего ряда», потом «обычно» — контраст слышен самому человеку |
| **Мгновенная конкретная обратная связь** (ELSA, Duolingo Speak) — работает, если указывает на одно измеримое | Пит даёт ОДНУ заметку за сессию и только по тому, что измерено: пропуск, порядок, темп, паузы, громкость |
| **Зеркало своего голоса**: сравнение с образцом — главный инструмент актёрского коуча | Акт 6: дубль записывается и играет после диктора; сравнение прямо на дорожках: две ленты пилюль, Пит сверху и ты снизу |
| **Желательные трудности** + **короткие сессии**: ~90 с с нарастающей сложностью удерживают внимание | Шесть актов, каждый короче 30 с, сложность растёт, никаких повторов ×3 подряд |
| **Внешняя награда вытесняет интерес**, если велика | XP настоящий, но с потолком, как в «Скажи вслух»; главная награда — услышать себя рядом с диктором |

## 2. Персонаж: Пит-тренер
- Говорит от первого лица, коротко, по делу, без оценок личности («не получилось слово», не «ты ошибся»).
- Метафора сцены: разминка, сборка, читка, прогон, без текста (off-book), дубль, просмотр.
- Одна реплика на событие, не чаще раза в 6–8 с; пока человек говорит — молчит (микрофон, режим «закрывать микрофон»).
- Стиль реплик — как легенда уроков (переписка с другом): коротко, часть с маленькой буквы, без «Верно!/Отлично!», без терминов и пола ученика; озвучиваемые — без смайликов, эмоция словами. Для озвучки ElevenLabs в текстах нет точек, многоточий, восклицательных знаков и тире (— и –), только запятые и «?». Тексты — решения владельца (2026-10-31), v3.3.82; все в `rehearsalLines.js`. Вариантов нет: у старта и итога два текста по номеру запуска в одном тапе («первый раз / ещё раз»), у сборки (`rh_build`, `rh_clear`) прежние по три случайных, у остальных один.

| Момент | Реплика Пита (v3.3.82, решения владельца) |
|---|---|
| Старт, первый раз (`rh_start`) | «Повторим то, что учили, и прокачаем произношение» |
| Старт, ещё раз (после «Ещё минутку?», `rh_start_b`) | «Окей, возвращаемся к знакомым словам и улучшим произношение» |
| Акт 1, старт | «давай разомнёмся, я показываю перевод, а ты говоришь слово по-английски» → отсчёт тремя нотами → первое слово (нет слов с карточкой — акта нет) |
| Акт 1, промах | «Опа, кажется, слово немного забылось, повторим завтра» |
| Акт 2, «Различи» (`rh_discern`, v3.3.87) | «Сейчас скажу слово, а ты найди его среди трёх похожих» |
| Акт 3, старт | «Собираем фразу с конца, так конец звучит увереннее всего» (и прежние `_b`, `_c`) |
| Акт 3, последняя ступень | «А теперь чётко, как для последнего ряда» → всегда второй «И ещё раз, только расслабленно, будто болтаешь с другом» |
| Акт 4, читка (`rh_read_why`) | «Сейчас скажу фразу целиком, следи за подсветкой и повтори в том же ритме» |
| Акт 5, без текста | «Ну-ка, по памяти, я подскажу, если застрянешь» |
| Акт 5, застрял | голос «Начни с» (`rh_blind_hint_pre`), затем слово из библиотеки слов; подпись на экране «Начни с {word}» |
| Акт 6, запись | плашка «Дубль» → отсчёт тремя нотами → «поехали» → запись |
| Акт 6, просмотр | «Послушаем по очереди и сравним произношение, сначала я, потом ты»; дорожки плавно останавливаются, на них появляется сравнение (v3.3.86) |
| Заметка (v3.3.87, п. 13 владельца): два слоя. Пит озвучивает общий вердикт после прослушивания (`rh_note_*`, `mirror/noteLine.js`), а текст плашки с конкретикой стоит МЕЖДУ горизонтальными пилюлями «Пит» и «твоя фраза» | |
| · запись не получилась (`rh_note_fail`) | Пит «Запись не получилась, попробуем в другой раз» · плашка то же |
| · потерялось одно слово (`rh_note_missing_one`) | Пит «Одно слово потерялось, посмотри, какое» · плашка «„trying“ потерялось» |
| · потерялось несколько (`rh_note_missing_few`) | Пит «Пара слов потерялась, посмотри, какие» · плашка «„trying“ и „learn“ потерялись» |
| · потеряно почти всё (`rh_note_missing_all`) | Пит «Тебя я почти не расслышал, скажи чуть громче» · плашка то же |
| · порядок (`rh_note_order`) | Пит «Порядок слов сбился, послушай» · плашка «„to learn“ прозвучало раньше „trying“» |
| · темп быстрее (`rh_note_fast`) | Пит «Ты говоришь быстрее меня, это нормально, но лучше повторять за мной» · плашка «не торопись в произношении» |
| · темп медленнее (`rh_note_slow`) | Пит «Ты говоришь медленнее меня, лучше не медлить» · плашка «лучше не медлить» |
| · пауза (`rh_note_pause`) | Пит «Не делай такую длинную паузу посреди фразы» · плашка «пауза перед „to learn“» |
| · тихо (`rh_note_loud`) | Пит «Лучше говорить громче, чтобы я понял твои слабые места» · плашка «в следующий раз говори громче, чтобы я тебя понял» |
| · лишние слова (`rh_note_extra`) | Пит «Мне кажется, я услышал лишние слова» · плашка «лишнее: „the“» |
| · чисто (`rh_note_clean`) | Пит «Всё на месте, звучит естественно, скоро я буду учиться у тебя» · плашка особая: золотая, с бликами, «Идеальное произношение!» |
| Финал, первый раз (`rh_done`) | «Рад, что мы потренировались вместе, хочешь ещё?» |
| Финал, ещё раз (второй и далее, `rh_done_b`) | «Здорово получилось, с каждым разом всё увереннее» |

Отсчёт тремя нотами (до — ми — соль, пауза 0,5 с, как перед стартом в гонках; `rehearsalCountdown.js`, звук — игровой AudioContext) играет перед разминкой (после реплики Пита) и перед дублем (после плашки «Дубль», до «поехали»); в режиме «тап вместо речи» тоже. Номер запуска — `plan.run` (0 в первом плане тапа, «Ещё минутку?» даёт +1; «Игра заново» из HUD и шлифовка одного акта — первый запуск).

## 3. Сессия: шесть актов, ~90 с (порядок с v3.3.87)
Фраза дня: `I'm | trying | to learn` (3 куска), перевод, озвучка ElevenLabs, 2 слова «к повтору»
(`trying`, `learn`), карточка `I'm` → «я», у `learn` двойники `earn` и `lean` из промахов. Разминка — только по словам с карточкой перевода (`trying`, `learn`, `I'm`), «к повтору» первыми; служебного `to` и слов без карточки в ней нет. Время — ориентир, акты пропускаются по правилам ниже.

| # | Акт | Цель | Механика на дорожках | Ввод | ~с |
|---|---|---|---|---|---|
| 0 | Заставка | Настроить | Фраза падает сверху, перевод под ней, три дорожки открываются | — | 4 |
| 1 | **Разминка** | Припомнить слова | По одному слову: над дорожкой перевод, пилюля едет, человек говорит слово. Участвуют ТОЛЬКО слова с карточкой (перевод есть; решение владельца, v3.3.87): «к повтору» первыми (самое просроченное первым), остальные слова с карточкой после них вперемешку по семени. Слово без карточки дорожке нечем подписать, поэтому его нет. Служебные слова (`to`, `a`, `the`, `of`, `and`, `or`, `in`, `on`, `at`, `is`, `am`, `are`, `be`, `do`, `it` и др., `rehearsalStopWords.js`) не идут даже с карточкой. Повторы слов фразы схлопнуты. Фраза из одного слова — слово идёт всегда. Нет ни одного слова — акта нет | Vosk, словарь: слова фразы + двойники | ~3 с на слово (потолок 12 слов, но карточек в плане не больше 8) |
| 2 | **Различи** (если есть двойник) | Развести похожие | Сразу после разминки (v3.3.87; правило «пропуск при ≥ 3 промахах» для него больше не действует, пропуск только без двойников). Пит объясняет: «Сейчас скажу слово, а ты найди его среди трёх похожих». Три пилюли выкатываются по очереди, на каждой написано слово (earn / learn / lean), и они молчат (раньше каждая пилюля озвучивала своё слово); слово звучит ОДИН раз, когда открылась последняя пилюля и три дорожки уже на экране (перед тройкой слово больше не звучит: это слишком подсказывало). Найти его надо среди написанных. Тап по услышанному → сказать слово. ВСЕГДА три дорожки (решение владельца, v3.3.85): слово и два других — двойники, а если их меньше двух, нехватку добирают слова фразы; верное слово на случайной дорожке (по семени), во второй подсказке на другой. До слова тап не засчитывается | тап + Vosk (словарь из тройки) | ≤ 12 |
| 3 | **Сборка с конца** | Порядок, уверенный конец | Ступени [2] → [1,2] → [0,1,2]: диктор 1 раз, человек 1 раз (промах — ступень ещё раз, не больше одного повтора). На последней ступени: «чётко» → «обычно» (две пилюли) | Vosk, словарь ступени | 25 |
| 4 | **Читка** | Ритм, интонация | После сборки (v3.3.87: поменяли с «Сборкой» местами). Читка-караоке: подписи кусков над дорожками — белые; диктор говорит фразу один раз, и слова заливаются зелёным синхронно с его голосом. Впереди идёт курсор «\|»: перед первым словом вырастает из точки до полной высоты, идёт по слову слева направо, оставляя его зелёным; после слова сжимается в кружок, кружок плывёт к следующему слову ровно столько, сколько длится пауза, и перед словом снова вырастает в «\|»; в конце «\|» уходит в ноль, фраза остаётся зелёной. Перед очередью игрока зелёное плавно уходит. Игрок читает «тенью» один раз: заливка и курсор идут за его голосом (слова слушателя Vosk: сколько слов фразы уже сказано, идёт ли речь); без речи курсор ждёт у следующего слова. Тайминги слов — равномерно внутри куска по длине куска (по буквам), у озвучки куска по словам таймингов нет. Слабое устройство — без курсора, слова просто становятся зелёными по очереди | Vosk, вся фраза | 12 |
| 5 | **Без текста** | Припомнить целиком | Подписи кусков убраны, перевод тоже. Фраза 2 раза. Застрял (3 с тишины) — Пит подсказывает первое слово, подпись куска на 2 с | Vosk, вся фраза | 15 |
| 6 | **Дубль и зеркало** | Услышать себя | Отсчёт, запись фразы целиком (MediaRecorder из потока игры). Сравнение прямо на дорожках, отдельного окна нет (решение владельца, v3.3.86): после дубля дорожки плавно останавливаются сами, на них две ленты пилюль — верхняя Пит, нижняя ты, кусок i на дорожке i (цвет дорожки, подпись «Пит» / «Ты» на самой пилюле, подписи кусков над дорожками как обычно); у Пита пилюли залиты полностью, у тебя по измерениям (кусок сказан — залита, пропущен — пустая с полосками промаха). Через 0,4 с после остановки сам (и по кнопке «Сравнить» / «Ещё раз») играет диктор, потом дубль, звучащий кусок светится (пилюля и вспышка дорожки). Одна заметка Пита — подписью над дорожками, «Дальше» ведёт в итог | запись | 25 |
| 7 | Итог | Закрепить | Фраза, перевод, темп (×1,2 к диктору), заметка, XP, «Ещё минутку?» | тап | — |

### Правила пропуска и сокращения
- Нет озвучки кусков → читка без заливки под голос Пита (голос системы, без таймингов; у игрока заливка идёт как обычно), зеркало без подсветки кусков диктора по словам (тайминги из длин кусков библиотеки).
- Нет Vosk → игра не стартует (как сейчас): на экране уведомление «Нужно скачать».
- Слово из акта 1 промахнулось дважды → в акте 5 («без текста») его кусок получает подпись-подсказку.
- 3 и больше промахов к акту «без текста» (разминка, сборка, читка) → «без текста» один раз вместо двух, зеркало остаётся (это главное). «Различи» от промахов не зависит: оно стоит до сборки и пропускается только без двойников.
- Фраза из одного куска (слово) → акты 1 и 3 схлопываются в «слово ×2» (за ним «Различи», если есть двойник), читки нет, «без текста» — слово по переводу, зеркало — слово (две пилюли на средней дорожке).
- Нет ни одного слова с карточкой (и не одно слово) → разминки нет, сессия начинается со следующего акта.

### Что измеряем (только это и попадает в заметку)
| Измерение | Откуда | Заметка |
|---|---|---|
| Пропуск / лишнее слово | Vosk final + `analyzeTargets` | «„trying“ потерялось» |
| Порядок кусков | seq ступени | «„to learn“ прозвучало раньше „trying“» |
| Темп относительно диктора | длительность дубля / длительность озвучки (тайминги) | «быстрее меня на треть» |
| Паузы между кусками | тайминги слов Vosk (`stats.words`) против таймингов диктора | «пауза перед „to learn“ длиннее» |
| Громкость | RMS дубля против RMS озвучки (нормализованной) | «тише, чем нужно для сцены» |
Качество звуков не оцениваем — Vosk этого не умеет; Пит об этом не говорит.

### XP и память (симуляция сейчас, RPC позже)
- За сессию: +1 XP за слово «к повтору», сказанное верно в акте 1 или 5; потолок — общий с «Скажи вслух» (10 в день).
- Слово с промахом → `due_on = завтра`, шаг не меняется; без промахов → обычный шаг лесенки.
- Фраза → `phrase_memory.consolidated_at = сегодня`; одна фраза не чаще раза в 3 дня.
- Сейчас: всё пишется в `rehearsalSim` (память сессии браузера, видно в журнале отладки), ничего на сервер.

## 4. Данные: интерфейс плана и симуляция
```
RehearsalPlan {
  phrase: 'I'm | trying | to learn', translation: 'Я пытаюсь учиться', lang: 'en-US',
  chunks: ['I'm', 'trying', 'to learn'],
  words: [ { text:'trying', translation:'пытаюсь', due:true, lapses:1, confusers:[] },
           { text:'learn',  translation:'учиться', due:true, lapses:2, confusers:['earn','lean'] } ],
  stressed: [1, 2],                 // ударные куски (пока вручную в фикстуре, заливка читки их не использует)
  audio: { phrase: { url, timings:[{word, start, end}] } | null, words: lib },  // phrase_audio ElevenLabs | библиотека слов
  source: 'sim' | 'memory' | 'node'
}
```
- `rehearsalFixtures.js`: 3–4 готовых плана (три куска с двойником и карточкой `I'm` → «я»; два куска без озвучки фразы; одно слово; фраза без
  слов «к повтору») — переключатель в Админ → «Голос» → «Тест игры» → «Репетиция (симуляция)», JSON можно править.
- Поставщик плана — одна функция `planFor(source)`: сейчас фикстура, потом `wordMemory`/`phraseMemory` (этап 1 плана) и
  нода `rotate_phone` (автор задал фразу сам). Сценарий от источника не зависит.

## 5. Как это ложится на движок
- Сейчас: рецепт (`wordLaneRecipe.js`) → стадии (`wordLaneStages.js`) → директор (`useWordLaneFlow.js`) → движок пилюль.
- Новое: `rehearsalRecipe.js` строит стадии актов из `RehearsalPlan` (тот же формат стадий + новые типы):
  `warmup` (слово по переводу — пилюля в дорожке слова, цель — слово), `discern` (есть, новый источник запутывателей; слово один раз при трёх дорожках), `build` (есть),

## 8. Случайность внутри актов (решение владельца, 2026-10-30)
Порядок актов фиксированный (разминка → различи → сборка с конца → читка → без текста → дубль и зеркало → итог, с v3.3.87): он несёт педагогику.
Разнообразие — ВНУТРИ актов, по правилам, с семенем от даты и фразы (одна сессия воспроизводима, разные дни разные):
- **Разминка**: слова — слова фразы с карточкой, без служебных; первое — самое просроченное, потом остальные «к повтору» вперемешку, потом остальные слова с карточкой вперемешку; дорожка слова — случайная из трёх (не всегда своя).
- **Читка**: одна реплика «зачем» (`rh_read_why`); заливка и курсор не случайны — идут за голосом.
- **Сборка с конца**: ступень «чётко / обычно» — случайно, какая первая; при двух кусках иногда [1] → [0,1], иногда [0] → [0,1].
- **Без текста**: порядок двух проходов и какая подсказка первой (первое слово / перевод куска) — случайно.
- **Различи**: три дорожки всегда; какие два других слова (двойники, при нехватке — слова фразы) и на какой дорожке стоит верное слово — случайно; ряд дорожек перемешан.
- **Дубль и зеркало**: порядок «сначала я, потом ты» фиксированный; заметка Пита одна на измерение (без вариантов: с v3.3.87 вердикт — реплика `rh_note_*` плюс текст плашки, «чисто» — одна золотая плашка).
- **Реплики**: у каждого ключа 2–3 варианта текста, выбор случайный, повтор подряд запрещён.
Не случайно никогда: первое слово разминки (самое «просроченное»), структура ступеней сборки, зеркало последним.
Предложение на потом (не решено): короткий сценарий для повторной встречи с фразой и 30-секундный для уверенной.
