# make-lesson — надёжная сборка урока

Правила — источник правды: `lesson-drafts/rules.json` (выгрузка из окна правил, кнопка «⬇ Правила для Claude»). Если файла нет — попроси пользователя вставить JSON из кнопки и сохрани его в `lesson-drafts/rules.json` (без него берутся устаревшие дефолты).

## Шаги (строго по порядку, не пропускать)
1. **Промпт**: `node scripts/lesson-prompt.mjs "<тема>"` — прочитай целиком: формула, правила R1…Rn, формат нод. Это твоё ТЗ, не пересказывай его из памяти.
2. **План** (в чат, коротко): части урока; в каждой — что ученик замечает / делает сам / чем усложняется. Покажи пользователю и дождись «го», если урок новый и большой.
3. **Урок**: напиши JSON в `lesson-drafts/<имя>.json` (образец структуры: `lesson-drafts/trying.v2.json`, заметки `src/features/canvas/lesson-io/AUTHORING_NOTES.md`). Для больших уроков удобнее скрипт-генератор в scratchpad, не в репо. Выделения — ТОЛЬКО разметкой `{g:..}` `{w:..}` `{u:..}` `{b:..}` `{p:..}`, массив `highlights` не пиши. Нужны `ref`, `type`, `seq`, `pos`, `triggers`.
4. **Шлюз**: `node scripts/lesson-gate.mjs lesson-drafts/<имя>.json --fix-seq`. Пока есть замечания — исправляй урок и запускай снова (до 5 кругов). Шлюз ловит формат, ритм (R-text-run, R-tautology), say_phrase, ответы, подсветки.
5. **Судья**: запусти агента `pithy-lesson-judge` (Agent, subagent_type `pithy-lesson-judge`) с путём к файлу. Получишь JSON нарушений. Исправь урок по каждому `ok:false` (если судья ошибся — зафиксируй причину в отчёте, не спорь молча). После правок снова шаг 4, затем судья ещё раз. Максимум 3 круга судьи.
6. **Отчёт пользователю** (коротко, по-русски): сколько нод/зон; что осталось озвучить/загрузить руками (список из шлюза); какие замечания судьи не исправлены и почему; путь к файлу. Не заявляй «всё чисто», пока шлюз и последний круг судьи не пройдены — если что-то осталось, скажи прямо.

## Нельзя
- Отдавать урок, не пройдя шаги 4 и 5.
- Выключать/обходить правила, чтобы пройти шлюз (в т.ч. править `rules.json` ради прохождения).
- Придумывать файлы озвучки/фото: для новых — `needs` / `needsVoice` и `imagePrompt`, как в легенде.
- Пушить в git без явной просьбы пользователя.
